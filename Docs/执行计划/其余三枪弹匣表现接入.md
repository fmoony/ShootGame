# 其余三枪弹匣表现接入

- 日期：2026-09-29。
- 基线：Rifle 的 Detach / Insert 与抓握配置已经人工验收。
- 范围：Pistol、AWP、GrenadeLauncher；继续使用既有纯本地弹匣代理。

## 当前资产与处理方式

Pistol TP Reload 播放 MM_Pistol_Reload，AWP 与 GrenadeLauncher 共用 MM_Rifle_Reload。
三枪 FP Root 均接在 Copy Pose From Mesh，不另建 FP 换弹时间轴。
AWP 与 GrenadeLauncher 已随共享 Sequence 获得 Rifle 的 Magazine Notify。
Pistol 补充自己的 Detach / Insert Notify，其余三枪分别写入 FP/TP GripTransform。
自动接入阶段未改 Rifle 的抓握配置和 Sequence，后续人工调整一并保留。

脚本先按换手帧采样角色姿态，求出枪上 MagazineSocket 相对 hand_l 的变换。
该值是最终局部姿态，Scale 固定单位值；不修改弹匣 Pivot、Socket 或模型。
三枪 FP/TP 当前使用相同角色网格和 Copy Pose，分别采样后初值相同。
后续可分别在 DT_WeaponData 中微调，并继续保持 Scale 为 1。

Pistol 30 fps 姿态采样显示：拔匣音效约 0.375 秒时左手已离弹匣约 47 cm。
因此不能直接使用音效时间计算抓握配置。
初始 Detach 使用第 1 帧，Insert 使用第 31 帧；保留现有音效时序。
这些时机与握持初值仅用于首次接入；最终以人工调参后的资产为准。
用户已确认三枪视觉验收通过，部分参数由用户在编辑器中调整。

公开 MCP 支持图查询，但没有 Sequence Notify 或 DataTable 写入接口。
使用 Unreal Python 独立进程执行资产修改，应用前备份两个目标包。
仅保存 MM_Pistol_Reload 和 DT_WeaponData，并核对非目标字段不变。
用户关闭 Editor 并等待进程退出后完成保存；重新打开即可加载本轮资产。
ABP_FP_Pistol 的已有工作区改动保留，本轮不修改其图结构。

## 五条不变量的含义覆盖

### Invariant 1 Owner Immediate Feedback

- 触及：Owner FP 弹匣换手表现与本地动画的对应关系。
- 不应改变：本地换弹窗口、预测来源及服务器确认前启动表现的边界。
- 新增证据：FP Copy Pose 链路查询、分侧 Detach 测试及 Sequence Notify 配置验证。
- 范围外：RTT 下输入到表现时序；本轮不修改 Ability、输入或网络触发入口。

### Invariant 2 Local Prediction Obeys Weapon Rules

- 触及：多枪纯表现和 Reset 收敛。
- 不应改变：已知规则门控、权威真值读取和误预测边界。
- 新增证据：生产网格上的 Detach/Reset、幂等、隐藏状态及 Ammo 不变断言。
- 范围外：射击限速和服务器 Reject 场景；其生产路径没有本轮修改。

### Invariant 3 Server Is Final Authority

- 触及：配置表保存可能误写弹药或事务字段的风险。
- 不应改变：动作校验、Accept/Reject 和服务器独占结果。
- 新增证据：非 Grip 配置字段逐项对照、Ammo 不变和无 RPC/复制字段增量检查。
- 范围外：服务器事务网络时序；本轮不修改 Reload Gameplay 或权威调用链。

### Invariant 4 Remote Is Confirmed Only

- 触及：Remote TP 代理从既有服务器确认的 Reload 动画接收 Notify。
- 不应改变：Remote 表现来源，不引入 Owner 预测广播或额外远端结果。
- 新增证据：TP Sequence 路径审计与 Notify 配置验证，TP 分侧运行时测试。
- 范围外：跨进程 Authority Commit 到 Remote 表现的时序；复制链无本轮调整。

### Invariant 5 Exactly One Authority Result

- 触及：共享 Sequence 或重复 Notify 可能重复换手。
- 不应改变：一次本地动作边界、一次表现和一份服务器结果。
- 新增证据：Sequence 每阶段 Notify 恰好一个，重复 Detach/Reset 幂等且 Ammo 不变。
- 范围外：事务、Projectile 和 Listen 双角色计数；不新增相关入口。
