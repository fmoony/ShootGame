# 武器贴墙稳定与瞄准表现收尾实施计划

> 状态：执行中。阶段 0 的 Rifle 左手握持视觉基线已于 2026-08-25 验收通过；当前只进入阶段 1 的贴墙抖动隔离实验。

## 1. 背景与已确认事实

- Rifle 第三人称左手已经能够基本贴合握把；当前校准结果先作为可回退基线，不再继续移动武器 Socket。
- 第一人称 `ABP_FP_Weapon` 每帧从相机向前 Trace 10000 单位，并在命中位置和远端终点之间直接选择 `Aim Target`；该值直接进入第一人称 Control Rig。
- 近距离命中点会让 Aim Target 进入极短距离，命中状态在障碍边缘变化时还会产生大跨度目标切换，这是贴墙抖动的首要嫌疑。
- `FAnimNode_ShooterAimIK` 当前把最多 30 度的残差集中施加给 `hand_r`；左手 IK 则求解整条左臂，快速转向时两侧手臂的处理不对称。
- `PresentationAimTarget` 当前由服务器以 10 Hz 采样，变化门槛为 50 cm / 3 度，观察端指数平滑速率为 8/s；快速转向会叠加采样、复制和平滑延迟。

## 2. 目标与边界

### 2.1 目标

- 第一人称贴墙静止、沿墙移动和快速进出障碍范围时不再抖动。
- 将稳定瞄准方向与武器障碍收缩拆成两个独立表现量。
- 让远端第三人称瞄准更快跟随拥有者真实视角，同时保持弱网下稳定。
- 在同步输入稳定后，改善快速视角移动时的右手腕、左肘和双臂组合姿势。
- 保持 Rifle 当前左手握持基线，Pistol 不错误启用 Rifle 左手 IK。

### 2.2 非目标

- 不修改服务器权威开火、命中、Spread、Projectile、伤害和 GAS 事务。
- 不复制骨骼姿势，不使用逐帧 Reliable RPC。
- 不在证据不足时重做整个第一人称 Control Rig 或第三人称动画架构。
- 不创建一次性蓝图资产修改 Commandlet；蓝图和 Control Rig 的视觉节点由人工按精确说明修改。
- 不在本计划中接入 Pistol 左手 IK。

## 3. 实施顺序

```text
阶段 0：保存 Rifle 左手握持基线（已通过）
→ 阶段 1：固定远端 Aim Target 隔离贴墙抖动
→ 阶段 2：拆分瞄准目标与武器障碍表现
→ 阶段 3：改造第三人称快速瞄准同步
→ 阶段 4：细化手臂姿势与 IK
→ 阶段 5：清理、回归与归档
```

必须先稳定上游数据，再调整下游骨骼。禁止用动画调参补偿过期网络目标，也禁止用网络平滑掩盖本地 Control Rig 的近距离奇异姿势。

## 4. 分阶段执行

### 阶段 0：Rifle 左手握持基线

状态：人工视觉验收通过。

基线目标 Transform：

```text
Location X=-29.886 Y=7.307 Z=-1.157
Rotation X=95.203 Y=9.546 Z=-120.477
```

完成条件：

- `Shooter Aim IK → Shooter Left Hand IK` 顺序保持不变。
- Rifle 水平和常用俯仰范围内手掌基本贴合握把。
- 临时逐帧 Print 不再进入执行链。
- 后续任何阶段出现姿势回归时，可以恢复到本阶段资产状态。

### 阶段 1：贴墙抖动隔离实验

只修改第一人称 `ABP_FP_Weapon` 的 Aim Target 数据来源：

```text
Camera World Location + Camera Forward Vector * 10000
→ Set Aim Target
```

临时绕过 `Line Trace → Select Vector → Hit Location`，但保留原节点，不删除，不修改开火逻辑。

人工验收矩阵：

| 场景 | 观察内容 |
| --- | --- |
| 正对墙面静止 | 枪和手臂是否停止高频抖动 |
| 沿墙左右移动 | 是否仍在某些碰撞边界抽搐 |
| 快速靠近与离开 | 是否只剩平滑不足，而非方向翻转 |
| 墙角反复扫过 | Hit/No Hit 切换是否仍影响 Control Rig |

阶段门：

- 抖动消失：确认 Aim Target 近点/切换是根因，进入阶段 2。
- 抖动仍存在：恢复原线，停止新增插值，继续只读审计 Control Rig 内部 Aim 求解。

本实验由人工完成蓝图连线与视觉判断；Agent 随后只读复核连线。

### 阶段 2：拆分瞄准与障碍表现

建立两个互不替代的数据：

```text
ViewAimTarget          稳定相机方向，只驱动瞄准
WeaponObstructionAlpha 障碍距离映射，只驱动收枪表现
```

推荐结构：

- ViewAimTarget 始终使用相机前方稳定远点，不消费近距离 Hit Location。
- 使用短距离 Sphere Trace 或 Capsule Trace 检测武器占用空间，忽略自身角色与当前武器。
- ObstructionAlpha 使用独立进入/退出距离形成迟滞，并使用较快收枪、较慢恢复的插值。
- 将 ObstructionAlpha 作为独立 Control Rig 输入或局部附加 Transform；不得修改真实开火目标。

完成条件：静止贴墙、沿墙移动和快速进出均无抖动，收枪过程连续，准星与服务器开火结果不变。

### 阶段 3：第三人称快速瞄准同步

现有服务器 10 Hz 采样路线替换为表现专用链路：

```text
拥有者本地即时 Aim Target
→ 受限频率 Unreliable Server RPC
→ 服务器有限值、距离和频率校验
→ PresentationAimTarget
→ COND_SkipOwner 属性复制
→ 观察端短窗口平滑
```

首轮候选值：

```text
发送频率：20 Hz
角度门槛：约 1 度
距离门槛：约 20 cm
保活更新：0.2 秒
```

首轮不做角速度外推。只有在 20 Hz 输入和自适应收敛完成后仍有量化证据表明延迟不可接受，才新增受限外推阶段。

完成条件：拥有者不消费服务器回传值；丢包不影响权威开火；Listen Server、Dedicated Server 和普通观察客户端都能稳定看到快速转向；停止转动后不来回修正。

### 阶段 4：手臂姿势与 IK 细化

先执行隔离矩阵：

| Shooter Aim IK | Left Hand IK | 目的 |
| --- | --- | --- |
| 关 | 关 | 原始动画基线 |
| 开 | 关 | 只检查右手枪口残差 |
| 关 | 开 | 只检查左臂求解 |
| 开 | 开 | 检查最终组合 |

实施方向：

- 上半身 Aim Offset / 分层姿势吸收主要俯仰和转向。
- Shooter Aim IK 只处理小角度枪口残差，不让大误差全部集中在 `hand_r`。
- 根据隔离证据降低当前 30 度残差上限，候选区间为 8～12 度。
- 为左肘建立稳定、可解释的 Pole Target；不在未验证时写死角色轴。
- 节点顺序保持 `分层动画 → Shooter Aim IK → Left Hand IK`。

完成条件：原地快速转向、移动、跳跃、Fire、Reload、Equip 中无持续脱手、翻肘、腕部大角度折叠和明显一帧追逐。

### 阶段 5：清理与回归

- 删除本计划产生的临时 Print、实验 Select 和无意义变量名。
- 保留有范围控制的 Debug 开关，不保留默认开启的逐帧屏幕输出。
- Rifle 完整视觉回归；Pistol 验证左手 IK 保持关闭。
- 执行 Editor Build、Focused Automation、双客户端联机和必要弱网模拟。
- 更新开发记录、计划状态和 AGENTS 导航后归档。

- 下一步必须保存 `.uasset` 且只读 MCP 无法代替人工操作。

- 多种合法姿势需要主观视觉取舍。
- 蓝图存在未保存修改，继续操作可能覆盖人工工作。
