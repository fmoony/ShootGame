# Rifle 动画迁移与生产表现接入记录

日期：2026-10-11；环境：UE 5.6.1、Blender 4.5.8。
用户在隔离视觉验收后授权迁移修正版并接入生产动画，选择 K 切换且过渡中可反向。
本轮 UE 会话已确认保存且不由用户并行修改。未提交或推送。

## 完成范围

三个修正版通过 Unreal AssetTools 移到 /Game/Characters/Mannequins/Anims/Rifle：

- MM_Rifle_AimToLowReady_CorrectedGrip
- MM_Rifle_AimToLowReady_Down30
- MM_Rifle_AimToLowReady_Down60

每段仍为 26 个采样键、30 Hz、0.833333313 秒，使用原 SK_Mannequin。
迁移前后 26 个 Raw 和 26 个 Retargeted 姿态样本逐项完全相等。
保存并定向修复重定向后，旧路径消失、重定向器为零，实验引用也指向新路径。
证据：[迁移采样](asset_migration.json)、[最终资产审计](assets_final.json)。

生产修改只涉及 ABP_TP_Player、BP_ShooterCharacter 和原运行时动画数据源。
ABP 保留 ShooterThirdPersonAnimInstance 父类及原 WeaponAction 的 ArmedAim ↔ Reload。
ArmedAim 内加入 RifleReady 子图：ArmedAim ↔ AimTransition ↔ LowReady。
保留原 Locomotion、Arms Slot、Reload 和第一人称 CopyPose 接线。
生产图无实验资产依赖，不使用 Editor 夹具、测试 Skeleton 或 Natural Pitch Blend Mask。

K 节点在角色蓝图 EventGraph，只接受本地控制且当前装备有效 Rifle 的角色。
新过渡入场 P < -50° 选 Down60；-50° ≤ P ≤ -30° 选 Down30；其余选 CorrectedGrip。
边界计算仅容忍 0.0001° 浮点误差。活动过渡锁定素材，反向只改倍率而不重置时间。
从稳定 LowReady 抬枪时按当前俯仰重新选片，从末端以 -1 播放；降枪以 +1 播放。

原 Aim IK 权重随收枪时间释放，LowReady 为零；原 LeftHand IK 保留。
开火 Montage、换弹、装备、死亡、失去本地控制和换武器清除调试目标。
无新增 Gameplay 状态、Tag、Ability、RPC、复制属性或权威结果；不改变开火和换弹规则。
操作、工具与视觉检查见[当前表现说明](../../Rifle收枪动画表现.md)。

## 实现问题与解决

控制器原 SetupInputComponent 未创建蓝图按键所需绑定，因此改在角色蓝图放 K。
BP_ShooterPlayerController 已从本轮基线恢复，字节一致，没有修改控制器输入代码。
未激活的 SequencePlayer 不能可靠按当前 Sequence 查找，改用编译后的状态玩家索引。
俯仰转换存在边界舍入，加入微小误差容忍，并实测 -30°、-50° 两端及邻近值。
Fire Tag 可能同帧结束，补充原 Montage 播放快照清除表现目标，没有改 Fire 管线。
