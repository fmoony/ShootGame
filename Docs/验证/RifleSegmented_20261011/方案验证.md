## 实现

原动画为当前 CorrectedGrip 基准。
P < -60° 用 Down60；-60° ≤ P ≤ -30° 用 Down30；P > -30° 用 CorrectedGrip。
沿用 ArmedAim ↔ AimTransition ↔ LowReady 三态，收枪正向，LowToReady 从末端反向。
离开稳定状态时选片；活动期改角度或中途反向都保持当前片段和累计时间。
到达稳定状态后，下一次入场才重新选片。
选择代码不写累计时间，新入场仍由原状态机初始化。

## 真实 AnimGraph 验证

94 组、24,440 个固定 60 Hz 运行步，使用真实 Manny Simple、Rifle、Socket，IK 关闭。
输入为 0、30、60、-15、-29.999、-30、-45、-59.999、-60、-60.001、-75 度。
每角分别测试完整正反向、25% / 50% / 75% 中途反向，Mask 强度 0 / 1。
三类额外情景从 -45° 起步：收枪中、抬枪中、反向同时改到 -75°。

自动检查通过：

- 入场选片符合边界，正好 -60° 为 Down30。
- 活动期素材及选择次数不变，没有逐帧按角度硬切。
- 活动相邻帧按 ±1/60 秒推进，端点正常裁剪，没有累计时间重置。
- 全部情景最后回到 ArmedAim，完整情景经过 LowReady。
- 捕获变换全部为有限值；原三态及正反向机制仍有效。

完整反向入场从 0.833333313 降到 0.816666663 秒。
中途反向采样实际约为 26%、50%、76%，差异来自 60 Hz 取整。
50% 反向从 0.416666806 降到 0.400000125 秒，片段不变。
收枪中改到 -75°，仍用 Down30；在稳定 LowReady 后重新抬枪才用 Down60。
新反向入场右手首步约 0.0232 cm，证明共同末端可支持这种独立入场选择。
本轮没有实现活动播放中的跨动画混合。
