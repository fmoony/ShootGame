# Rifle 预览会话恢复与按钮使用说明

## 本轮首发提示词

排查当前为什么还在提示executing python scripts，以及你说的按钮如何使用

## 原因与处理

上一轮恢复编辑器仍带 ExecutePythonScript 参数。
有限检查脚本执行完成，但设置了 set_keep_python_script_alive(True)。
UE5.6.1 启动脚本执行器因此继续保持运行状态及 Executing Python Script 提示。
这是 Agent 收尾疏漏，不是检查循环仍在执行，也不是此前截图回调再次运行。

本地 EditorPythonExecuter.cpp 核对了通知创建、KeepAlive 判断及 RequestExit。
提示的 Cancel 与 KeepAlive=False 都会请求 QUIT_EDITOR，不能把它们当作只关闭提示。

用户本轮重新确认全部保存且不会编辑后，PID 46908 正常退出，没有强制结束。
已以普通方式打开 L_RifleTransition_Test，PID 47060，不包含 Python 启动参数。
实际窗口截帧确认执行提示消失，测试关卡正常显示，状态栏为 All Saved。
本轮没有改动代码、动画资产或生产配置，没有提交 Git。

## 按钮使用

1. 在关卡 Outliner 选中 Rifle Scheme A - Goal in Details。
2. 详情组件树选中最上方 Self，避免选成 Third Person Mesh 或 First Person Camera。
3. 在 Details 搜索框输入 Toggle，Rifle Test 分类会显示三个按钮。
4. 在视口菜单启用 Realtime，即可直接观察编辑器预览，无需先点击 Play。

- ToggleRifleTestGoal：ArmedAim 与 LowReady 互换。
  第一次降枪，再次抬枪；动作未结束时再次点击可检查中途反向。
- CycleRifleTestPitch：从 0 开始依次切到 +30、+60、-30、-60、0 度。
- PlayFireAnimationOnly：只播放已有 Fire Montage，不产生 Gameplay 开火。

本轮已实际选中预览 Actor，并留下 Toggle 搜索过滤，三个按钮可见。
没有点击动作按钮或改变 Goal/Pitch；视觉动作验收仍由用户继续执行。
运行中优先使用按钮，直接编辑 Actor 属性可能触发编辑器重建。
