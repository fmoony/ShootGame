# 躯干镜像并保留头手朝向（2026-11-18）

可见 Demo 已切换到新版本。只替换左前和右后样本，方向平滑保持 0.2 秒。
左前取右前的头与左右手朝向，右后取左后的头与左右手朝向。
在角色空间按相同侧别保留旋转，左右手的角色不互换。

## 实施

Root、骨盆、全部脊柱、腿和脚沿用全身镜像的逐帧组件变换。
头与手保留来源的组件空间旋转，颈部、锁骨和手臂逐节过渡。
手指采用来源局部姿态。手的位置随手臂变化，左手与右手的位置没有锁定。
保留肩臂、颈部与手指的骨长，未增加运行时 IK 或动画逻辑。

继续沿用原一秒、60 FPS 的周期，两个新资产使用原实验 Skeleton。
原有六个方向及 BlendSpace 采样位置和播放速率保持原配置。
原全身镜像、仅下半身镜像和保留整个上身朝向的资产均保留。

## 验证

离线目标数据中，镜像躯干与腿部逐帧相同。
头与左右手和来源的目标旋转差为零。
导入后核对原始数据和压缩数据，最大旋转误差约 0.00565°。

在真实可见 PIE 中，用实际键盘采集 495 帧。
通过骨盆、腿和脚匹配相位，测量稳定斜向各五帧的朝向。
头和双手相对来源的旋转差最大约 0.102°。
胸和骨盆相对全身镜像版的旋转差在 0.04° 内。
屏幕上可见胸随镜像转向，头和双手继续朝向来源方向。
手掌朝向满足本轮目标，握持位置与转向观感仍待人工体验。

短按松键后仍可能冻结在下沉的过渡帧。
四次短按的最低鞋面低于地面约 16–21 cm。
本轮以头与双手的朝向为范围，邻向接地仍保留为独立问题。
