# 恢复方向混合与下半身镜像（2026-11-18）

八向 Demo 已恢复 Forward、Right 两轴 0.2 秒平滑。本轮只替换左前和右后。
可见 PIE 已打开，等待体验上身姿态与连续转向。

## 动画处理

左前仍来源于四向 BlendSpace 的右前混合，右后仍来源于左后混合。
两段均使用已验证的一秒原生求值结果，保留 60 FPS、61 个采样点。
Root、骨盆、双腿、脚部辅助骨沿用全身镜像版本的变换。
从 spine_01 往上保留来源的父骨骼局部姿态与手臂侧别，随镜像骨盆运动。
手部辅助骨仍采用来源在 Root 下的局部变换，本轮没有引入运行时骨骼处理。

原始骨盆与镜像骨盆的旋转差峰值为 119°。
采用局部姿态可以避免把全部角度差压到腰下第一根脊柱骨。

## 骨骼和鞋面

烘焙输入的下半身组件空间数据与旧全身镜像逐帧相同。
保留的局部骨骼位置误差小于 0.00007 cm，旋转误差小于 0.00003°。
UE 导入后最大位置误差约 0.00149 cm，旋转误差约 0.00565°。

实际键盘短按和连续切换采集 2492 帧，每帧记录 89 根骨骼。
短按 A+W、D+S 各两次，每次三帧后松开。
四次松键冻结帧的鞋面最低点仍低于平面约 16.5–22.5 cm。
未消除进入斜向时的邻向穿地，当前改变的是上身并恢复方向平滑。

正前→左前、正后→右后各一次连续转向中，脚部最大单帧位移约为 26.1、28.5 cm。
此前 0 秒版本的相应采样约为 108.7、122.7 cm。
最大值用于诊断突变。各轮实际按键相位略有不同，连贯程度仍需人工验收。
稳定斜向采样的头、胸、手、骨盆与足部骨骼与新资产相符。
