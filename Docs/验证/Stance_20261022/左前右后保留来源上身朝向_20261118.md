# 左前与右后保留来源上身朝向（2026-11-18）

只替换左前与右后。左前的上身沿用右前，右后的上身沿用左后。
胸、头和双手在角色空间里的朝向保留来源，不随镜像骨盆转向。
八向 BlendSpace 维持 0.2 秒方向平滑。

## 实施

取既有逐帧原生混合与全身镜像数据，保留镜像后的 Root、骨盆、双腿和脚部辅助骨。
从 spine_01 到 spine_04 逐节减弱对骨盆转角的继承。
从 spine_04 往上保留来源的组件空间旋转与上身关节相对姿态。
保留每根上身骨的局部平移和原周期动作，单节脊柱动画旋转改动峰值约 29.8°。
新序列仍为一秒、60 FPS、61 个采样点，使用原实验 Skeleton。

BlendSpace 只替换两个斜向样本，其余六个引用、位置和播放速率保持。
源 FBX、旧镜像动画和实验 AnimBP 保留。没有改动运行时代码。

## 验证

Blender 烘焙输入逐帧对照，下半身组件变换与旧镜像一致。
UE 压缩姿态对照的最大角度误差约 0.00565°，最大位置误差约 0.00149 cm。

在可见 Demo 通过键盘采集 493 帧，覆盖短按、松开和连续转向。
稳定斜向各取五帧，先用骨盆和脚部匹配相位，再测胸、头、锁骨和双手的旋转。
左前相对右前、右后相对左后的最大旋转差分别为 0.031° 和 0.029°。
上一版随骨盆转动时，采样中胸部相对来源的旋转差可达约 93° 和 99°。
截图可见新版本的胸口和前臂维持来源方向，腿仍在执行镜像步态。
腰背过渡的自然度仍需在可见 Demo 中体验。

四次短按的最低鞋面仍低于地面约 17–21 cm。
此处是原有邻向混合接地问题。镜像下半身和 0.2 秒平滑的组合保留下来。
