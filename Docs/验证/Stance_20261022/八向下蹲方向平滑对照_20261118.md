# 八向下蹲方向平滑对照（2026-11-18）

本实验复现了左前和右后短按松键后的深穿地。
关闭方向平滑后，这四次短按的额外下沉减轻，连续转向出现明显的脚部跳变。
当前可见 PIE 保留 0 秒配置，等待人工体验。

## 修改与复现

- 在 `codex/ue-5.8` 上只修改 `BS_EightDirection_Mirrored` 的 Forward、Right 平滑时长。
- 两轴从 0.2 秒改为 0 秒，样本资产、坐标、速率和原生三角化保持原配置。
- 两组都运行同一地图、Pawn、AnimBP 和实际位移路径，使用可见浮动 PIE。
- 通过项目游戏窗口发实际键盘消息。先用 W 或 S 走到选定步态相位，再松开。
- A+W 或 D+S 各按住 3 帧，随后同时松开并观察冻结姿态。
- 两个方向各测两次相位，另测主方向与斜向之间的连续来回切换。
- 两组共 1052 帧，每帧采集组件空间中 89 根骨骼的实际姿态。
- 周期进度由引擎游戏时间与实际动画速率累计，四组对应松键相位差均小于 0.001。

## 短按松键

使用同一参考网格按运行骨骼姿态估算鞋面最低点，世界地面 Z=0。
负值表示低于地面。数值不直接作为自然度验收。

| 方向与采样相位 | 0.2 秒鞋面 Z/cm | 0 秒鞋面 Z/cm |
| --- | ---: | ---: |
| 左前，约 0.333 | -19.98 | -5.95 |
| 右后，约 0.667 | -20.24 | -6.33 |
| 左前，约 0.300 | -17.16 | -6.92 |
| 右后，约 0.617 | -20.54 | -4.68 |

两组松键后 Pawn 位移与脚部姿态变化均为零，确认短按会保留当时的姿态。
原配置画面中双脚有大段埋入地面。零平滑版的脚部轮廓明显更完整，仍有接地残差。

## 连续转向

| 转向 | 0.2 秒鞋面 Z/cm | 0 秒鞋面 Z/cm | 最大单帧脚部位移，0.2 → 0 秒/cm |
| --- | ---: | ---: | ---: |
| 正前 → 左前 | -21.01 | -6.92 | 26.4 → 108.7 |
| 正后 → 右后 | -19.50 | -6.16 | 28.5 → 122.7 |
| 左前 → 正前 | -15.57 | -4.28 | 19.2 → 91.0 |
| 右后 → 正后 | -17.77 | -3.67 | 20.6 → 92.6 |

单帧位移取两只脚的 foot／ball 中最大的组件空间距离，采样间隔约 1/60 秒。
这说明零平滑避开了深穿地的混合权重，但直接切换时脚部会大幅跳位。
连续动作的视觉接受度仍需在可见 PIE 中验证。
