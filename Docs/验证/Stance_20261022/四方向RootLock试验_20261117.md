## 数值结果

稳定八方向的 Root 位置变化小于 0.00002 cm，旋转变化小于 0.00003°。
前后左右四个主方向稳定段的 Root 位置与旋转均不再随周期变化。
原版本最大相邻记录 Root 位移约 198.29 cm，当前约 3.10 cm。
当前剩余位移来自方向切换时各素材首帧 Root 位置的混合。
因此消除了周期行进和大幅循环回跳，没有证明所有切换偏移为零。

四个主方向的骨盆 Z 在各自稳定播放时均恒定。
各方向高度仍各不相同，没有做统一高度处理。
这确认了副作用：原本烘焙在 Root 中的身体起伏和旋转也被冻结。
脊柱和头部仍保留部分局部运动，不代表身体原始运动已完整保留。

鞋部使用同一参考网格与原生运行骨骼做离线蒙皮估算。
地面沿用哈希未变化地图的已核实 Z=0；不是重新抬地面。
相交仅为左右鞋表面 BVH 候选，不等同完整碰撞或自然度判定。

## 行为依据

UE 5.8 本地 FRootMotionReset::ResetRootBoneForRootMotion 在 AnimFirstFrame
模式将整个 Root 变换恢复到首帧，包含位置和旋转，而非只去除水平净行进。
源码位于 Engine/Source/Runtime/Engine/Public/Animation/AnimCompressionTypes.h。
本轮观察与该实现一致；没有更改引擎或添加替代骨骼算法。

[Epic Root Motion 说明](https://dev.epicgames.com/documentation/unreal-engine/root-motion-in-unreal-engine)
