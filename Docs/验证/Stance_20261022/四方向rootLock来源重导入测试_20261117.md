输入目录：

D:/GameResource/Model/UETemplate/Animation/Crouch/rootLock

方向先结合骨架坐标与近地脚部反向扫动核对，再检查实际 PIE。
近地 ball 位移仅辅助识别方向，不作为鞋底触地判据。

四段新序列独立存于：

/Game/Experiments/Stance_20261022/FourDirectionRootLockSource_20261117

Skeleton 均为原实验 SK_FourDirection：

/Game/Experiments/Stance_20261022/FourDirection_20261117/SK_FourDirection

它是此前生产骨架的隔离副本；本轮没有更改它或生产 Skeleton。
新前行原件与此前 36 点、约 1.167 秒的前行不是同一段资源。
当前四段均无大幅净行进，整周期 Root 净位移小于 0.005 cm。
它们仍有父对象平移、旋转和身体起伏，不是静止 Root 的四个相同姿态。

原件按 SHA 保留于 SourceAssets/FourDirectionRootLockSource_20261117/Original。
来源路径、方向、长度和 SHA 见 Sources.json。
采用既有忠实父层烘焙导入管线，避免 UE 遗漏动画父对象。
只做固定参考坐标转换及父对象到 Root 的完整变换烘焙。
没有去除运动轨迹、重新制作步态、统一骨盆或修改支撑相位。
ImportReady 和四份 blend 保留于同一 SourceAssets 目录。

Blender 对原始源姿态的位置误差小于 0.00039 cm。
UE Raw、Retargeted 与 Compressed 对原始源姿态最大位置误差约 0.00043 cm。
最大旋转误差约 0.00187°；每段检查全部 31 个采样、89 骨骼。
这些误差只证明导入保真，不能证明自然度或接地合格。

新序列 Enable Root Motion=false、Force Root Lock=false。
Root Lock 模式字段保持默认 Ref Pose，因未启用锁定，不参与本次求值。
目录名 rootLock 代表用户提供的来源，不等于额外开启 UE Force Root Lock。
因此保留了新 FBX 已有的原地运动与身体起伏。
