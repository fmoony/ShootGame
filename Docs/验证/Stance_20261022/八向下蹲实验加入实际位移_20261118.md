# 八向下蹲实验加入实际位移

日期：2026-11-18；UE 5.8.4；分支 codex/ue-5.8。
已将当前八向原地预览改为 Pawn 实际移动，保留原八向动画及混合参数。
仅修改既有 Editor 夹具中的 TickFourDirection 和操作提示。

## 当前行为

- WASD 及组合键让 Pawn 按角色前后左右实际位移。
- 使用既有实验 MoveSpeed=150 cm/s，主方向与斜向等速。
- 动画输入继续按 L1 归一，命中当前八点菱形 BlendSpace。
- 世界移动方向单独按向量长度归一，避免斜向速度降为约 106 cm/s。
- 松键停止位移，并暂停在最后移动姿态；没有引入 Idle。
- T 同时暂停动画和位移，再按 T 继续。
- O 仍每三秒切换一个方向，现在会真实移动，位置不在切换时重置。
- V 保持原三种观察角度，鼠标转向维持原控制方式。

原 CalcCamera 已使用 Actor 世界位置计算相机位置。
因此相机会随实际移动跟随，本轮没有调整相机高度、距离、FOV 或骨骼眼点。

地图仍为：

/Game/Experiments/Stance_20261022/FourDirection_20261117/L_FourDirectionPreview

活动 AnimBP 仍引用 BlendMirrorEight_20261117/BS_EightDirection_Mirrored。
八段序列、原始输入、Skeleton、Root 设置和 0.2 秒方向平滑均未修改。

## 改动范围与实现

文件：Source/ShootGameEditor/Tests/Stance/ShooterStancePreview.cpp。

仅在八向预览分支按非零输入、非暂停条件调用 AddActorWorldOffset。
世界方向由 Actor Forward／Right 和当前方向比例组合，再做长度归一。
这是实验 Pawn 位移，不是脚部、骨盆或骨骼姿态修正。
复用既有预览的移动方式，没有接正式 CharacterMovement、碰撞、重力或网络预测。
其余旧 Stance 分支和生产 Gameplay 不变。

保护快照覆盖 390 个文件，包括实验资产、输入与生产 Runtime 源码。
仅上述预览 cpp 的 SHA 发生变化。
没有保存或改写动画资产，未启用 Root Motion 提取或 Force Root Lock。

## 编译与自动运行验证

项目 Editor 编译通过。
使用 -UsePrecompiled 和 -NoEngineChanges，未改写引擎源码或引擎模块。
仅修改既有 cpp，没有新增、移动或删除源码文件，因此没有刷新 VS 工程文件。
CodeGraph 命令不可用，本轮限定范围读取现有实验夹具，未扩展架构。

重新运行原生八方向采集，共 26 秒、60 FPS、隔帧记录。
得到 780 帧、69,420 条骨骼记录。
用骨骼实际组件坐标和世界坐标的刚体对应关系，还原 Actor 位移和偏航。
该步骤只分析已有运行数据，不进行骨骼 FK 或姿态回写。

验证结果：

- 八方向稳定段速度均约 150 cm/s。
- CSV 时间保留六位小数，计算区间约为 149.997～150.002 cm/s。
- 斜向与主方向速度一致，移动朝向符合输入。
- 初始零输入和末尾零输入的 Pawn 位移均为零。
- Pawn 垂直位置没有变化，未添加抬高角色或接地逻辑。
- 相邻采样 Actor 最大位移约 5 cm，符合 1/30 秒采样下的 150 cm/s。
- 与上一版固定位置运行的组件空间姿态逐骨对照，最大位置差为零。

因此增加的是 Actor 世界位移，没有改变八向动画求值。

## 实际按键与相机验证

通过本项目游戏窗口的真实按键消息测试 W、W+D、松键与 T。
测试期间持续只读记录 Actor、相机、动画输入和播放倍率。
按键在 finally 中全部释放，未作用于其他项目或应用。

Slate 回调的墙钟与游戏帧不完全同步，首轮墙钟记录仅留作过程证据。

## 边界与未解决项

150 cm/s 是现有实验步速，未针对各方向原始步幅调速。
本轮没有统一步幅、支撑比例、骨盆高度或身体前倾。
实际行走的脚滑与速度匹配仍需体验，没有以数值测试代替视觉验收。
此前前／左前、后／右后邻向下沉和穿模问题保持，未追加修复。
当前仍为隔离预览，不代表正式 CharacterMovement、碰撞或多人 Gameplay 验收。

可见 UE 已打开同一地图的干净手动 PIE，自动演示关闭。
点击画面后即可用 WASD 移动；松键停住，O 自动移动演示，V 换视角，T 暂停。
保留用户此前六方向验收记录；本轮不重新裁定它们的动作质量。
