## 制作与接入

- 从实际移动 BlendSpace 的前向 MF_Unarmed_Jog_Fwd 提取胸腔与锁骨周期运动。
- 使用已验收 LowReady 第 0 帧作为持姿基准，前三阶周期拟合消除循环接缝。
- 躯干相对基准的旋转峰值控制在约 3°，锁骨局部峰值不超过约 3°。
- 在 Blender 协调双臂，保持双手相对关系，再烘焙为 54 点、约 1.766667 秒的 FBX。
- 新序列配置 Local Space Additive，参考原 LowReady 的第 0 帧。
- 两个 AnimBP 均复制自当前生产图，父类仍是运行时 ShooterThirdPersonAnimInstance。
- 实验版在 AimTransition、LowReady 的原头颈修正之前插入标准 Apply Additive。
- 过渡权重读取原真实播放器的时间比例，并用标准 Ease 节点渐进处理；稳定 LowReady 为 1。
- 仅副本移动播放器配置 SprintStride 为 Leader，新循环为 Follower。
- 原过渡序列、RateScale 2.6、累计时间、反向规则、AO、Mask、IK 和头颈节点保持。
- 角色与 GameMode 均为生产蓝图的隔离副本，复用原 PlayerController 与真实 FP 链路。
- 实验 HUD 根据实际 AnimInstance 名称显示当前方案，不依赖屏幕消息显示开关。

## 已有地图与操作

使用原地图，不创建新地图：

```text
/Game/Experiments/RifleTransition/Segmented50_20261011/L_RifleSegmented_LowToReady
```

保留两个既有独立预览 Actor，新增实验平台、出生点、前方 Rifle 拾取物及天空。
原方向光用于实验平台，已移除本轮重复创建的灯光。
地图 GameMode Override 指向实验 GameMode；生产 Lvl_Shooter 未修改。

1. 以 1 名玩家 Play，从 PlayerStart 出生，向前走拾取 Rifle。
2. W + Shift 跑步，松开 Shift 抬枪，重新按住可在过渡中反向。
3. F6 使用实验版，F7 使用原版；绿色 HUD 显示当前实际方案。
4. 先选定方案，再用 F8 脱离观察 TP；重新附身后继续使用按键。
5. 脱离后可选 BP_SprintSwayCharacter 实例，在详情面板使用两个方案按钮。
   Use Sprint Sway / Use Original Pose 同样保留在角色副本蓝图中。

原版／实验版使用不同 AnimClass，切换会重新初始化实例；不要用切换瞬间评价自然过渡。
自然收抬枪的连续性应在同一方案内通过 Shift 检查。
旧两个独立 Actor 仍是素材预览，不替代新角色的真实 FP 验证。
