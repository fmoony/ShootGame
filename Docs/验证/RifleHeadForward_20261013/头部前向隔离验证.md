# Rifle LowReady 头部前向隔离验证

日期：2026-10-13。保留上一轮肩部与 Roll 方案，新增头颈前向候选。
本轮未修改生产资源、肩部动画、Mask、Gameplay 或网络源码，未提交。

## 调整依据

角色 Actor +X 是方向指示器前方，经真实 Mesh Transform 转换到 Body Component Space。
当前 Manny 的 Rest 面部朝向为 Body +Y；head Local 前向近似 +Y。
原 head 摄像机挂点相对旋转的前向也为 +Y，实际 TP 截图与此轴向一致。
neck 的骨骼长度轴不能当作面部前向，需反推各自 Rest Component 旋转。

| 骨骼 | Local 前向轴 x / y / z | Raw ADS 局部水平贡献 |
|---|---|---:|
| neck_01 | 0.2384 / 0.9712 / 0 | +7.64° |
| neck_02 | 0.2059 / 0.9786 / 近零 | +11.08° |
| head | 近零 / 1 / 近零 | +28.25° |

Raw ADS 取最近采样 0.233333 s；每节贡献在相同真实父骨骼姿态下与 Rest Local 比较。
此时 head 总水平偏角约 -2.84°，父级继承方向约 -31.09°。
真实 ArmedAimPose 还包含 AO，因此不能只反向抵消 head 的一个 Euler Yaw 分量。
最终图在 Pitch=0°、Hold=0.25 s 时的面部水平偏角约 -18.68°。
-60° 时原头部仰角约 -71.40°，水平投影偏角会扩大；不能直接施加 64° 的局部旋转。

新增节点保持当前前向的仰角，以角色前方的同仰角方向为目标，求最小 swing。
旋转按 20%／30%／50% 分配到 neck_01／neck_02／head，并转换为 Local Additive。
所有其他骨骼的 Additive 为零；不使用旧的“胸腔相对侧倾减少 80%”算法。
ArmedAim 不接入节点，过渡按真实播放器 t/T 平滑解除偏头，反向同步恢复。
总 swing 上限 28°，本轮测得最大 19.64°，单节局部修正最大约 9.82°。
本轮不是固定世界水平，也没有重写 AO 或抹掉自然 Roll。

Local Additive 依据 [Epic 5.6 动画序列文档](https://dev.epicgames.com/documentation/en-us/unreal-engine/animation-sequence-editor-in-unreal-engine?application_version=5.6)，并核对安装版 ApplyAdditive 的 Local Delta 累积行为。
这是实验节点的动态 Local Delta，不是已烘焙的独立动画素材；节点只在 Editor 模块。

实际 AnimGraph，Body Component Space，Hold=0.25 s，稳定 LowReady：

| Pitch | 原面部绝对水平偏角 | 新偏角 | 头部仰角：前 → 后 |
|---|---:|---:|---|
| 0° | 18.679° | 近零 | -32.612° → -32.612° |
| -60° | 64.401° | 近零 | -71.404° → -71.404° |
| +60° | 16.657° | 近零 | +43.300° → +43.300° |

54 组、16,200 帧覆盖三方案、三 Pitch、三 Hold 相位及完整／中途反向。
18 组修改后反向对照通过，其中新方案 9 组；状态与累计时间保持一致。
受测 root、pelvis、spine、肩部与双手 Transform 差为零；ArmedAim 差为零。
新方案全程最大仰角差 3.6e-7°，稳定 LowReady 最大水平偏角 8.0e-7°。
最大 head 骨骼位置变化 0.451 cm，状态边界新增单帧位移小于 0.001 cm。
以上数值关闭 IK；真实角色视口验证保留原 IK、FP CopyPose 和 Clearance。

返回玩家视角恢复原可见性，不修改任何生产 Mesh 可见性设置。
