# Rifle 实验视角继承正式角色对齐

本轮完成实验角色对正式第一人称链路的继承。正式资产、Runtime 源码和配置未改，未提交 Git。

## 使用入口

打开 `/Game/Experiments/RifleTransition/L_RifleTransition_ShooterCamera_Test`，
使用单玩家、Standalone 网络模式运行 Play，然后点击游戏视口。
关卡 GameMode 自动生成并附身实验角色，不需要手动配置相机。

| 按键 | 操作 |
| --- | --- |
| 鼠标 | 正式 Shooter 角色的视角输入 |
| 1 | ArmedAim / LowReady 目标切换，可在过渡途中再次按下 |
| 2 | 0、+30、+60、-30、-60 度循环；当前不在采样点时先回到 0 度 |
| 3 | 遮罩强度 0、0.5、1 循环；初始为 1 |
| V | 第一人称 / 外部观察切换 |

屏幕实时显示实际 WeaponAction 状态、目标、俯仰、遮罩强度、过渡时间、播放方向、
FP Scale、FP/TP 骨盆位置差、真实武器和最后操作。

## 最终实现

- `BP_RifleTransition_ShooterCharacter_Test` 直接继承正式 `BP_ShooterCharacter`。
  只覆盖 `PlayerThirdPersonAnimInstanceClass` 为现有隔离实验 AnimBP，添加本地调试组件。
- `BP_RifleTransition_ShooterGameMode_Test` 继承正式 `BP_ShooterGameMode`，
  只覆盖 DefaultPawnClass；PlayerController、CameraManager、PlayerState 沿用正式实现。
- 原有实验 AnimBP、三态状态机、两处 LBB 和遮罩资产字节级未变；TP 两项 IK 仍无节点。
- Editor 模块既有 Fixture 文件新增 `UShooterRifleCharacterDebugComponent`。
  只在本地单机实验运行，通过已有池、Inventory、Equipment 接口装备一把真实 Rifle，
  使原生 FP 修正取得有效角色、武器和网格数据。参数写入先于 TP Mesh 更新。
- 外部观察复用父蓝图备用相机，暂时把 TP 人体与武器 Primitive Type 设为 None。
  返回 FP 恢复 WorldSpaceRepresentation；原有 FP 相机参数、CalcCamera 不改。

本轮纠正此前调试 Pawn 的两个差异：正式蓝图 FP Scale 实为 **1.0**，不是原生构造器的 0.6；
普通 APawn 不能通过原生 FP 代理的 ShooterCharacter 检查。
本次继承正式蓝图与有效装备关系，直接复用原有 FP 动画代理。

## 验证与边界

- Editor 编译通过；源码 include 检查、`git diff --check` 通过。
- 重新加载资产确认 TP 实验类、正式 FP 类、正式 Controller 均正确。
  相机 FOV / FP FOV 为 90，FP Scale 为 1，位置与旋转保持父蓝图值。
- 单机真实窗口验证 1 / 2 / 3 / V：到达 LowReady，遍历 0、±30、±60 度，
  切换三档遮罩并返回 ArmedAim。鼠标继续走正式输入。
- FP 骨盆相对 TP 的组件空间位置差稳定为 12 cm，证明原生身体后移实际求值。
  外部观察为 0 cm，返回 FP 恢复 12 cm。
- 首轮 V 只显示影子；核查 UE5.6.1 SceneProxy 会对 WorldSpaceRepresentation 强制 OwnerNoSee。
  修正后重新运行，截图确认完整 TP 人体和武器可见，返回 FP 正常。
- 两次游戏运行均无运行时 Error、原有 FIRST_PERSON_POSE_FAILURE。
  既有文件哈希核查仅两份 Editor Fixture 源码与本轮临时进度文档变化；其余 932 份未变。

本轮对齐的是正式相机与 FP 表现链路。TP 姿态仍是关闭两项 IK 的遮罩实验输出，
枪械画面不应被当作正式完整瞄准系统的逐像素复现。既有 Fixture 仍固定站立数据，
本轮不增加移动动画或联机实验支持，也不宣称遮罩已经解决枪械位置漂移。
