# Rifle 收枪完成后肩带挪动：隔离衔接修正

日期：2026-10-14；基准提交 98d8e23。用户确认问题发生在进入 LowReady 的边界。
本轮不再抬肩，保留已有 LowReady 肩位；只制作过渡副本，等待视觉验收。

## 已确认的问题

当前 35% 抬肩方案的过渡末帧与 LowReady 起帧并未对齐。
Local clavicle_l 旋转差约 16.787°，clavicle_r 差约 1.979°。
切换时状态混合把左肩移到另一个目标，表现为收枪结束后又挪一下。
严格实际图测量中，左肩边界挪动约 3.369 cm，单帧峰值约 0.697 cm。
这是三维肩位变化，而非单纯肩部 Z 高度。

上一轮检查相对旧版的新增步长，不能证明原有绝对边界连续。
本轮补充绝对轨迹与切换阶段取证，不改写上一轮历史报告。

保留 ShoulderIdle_20261014 的 MM_Rifle_LowReady_Relaxed，未重新导入或保存它。

不增加补偿节点，不改变生产资源。

## 工具故障与处理

首次原生 Prepare 卡在 SetSkeleton → OnSetSkeleton → TryCancelAsyncTasks 的压缩等待。
用已安装 cdb 非侵入查看主线程栈，记录 SharedMutex 等待；不推断所有 UE 情况都有此问题。
尚未创建新 AnimBP，用户明确授权后，仅结束本轮 PID 22408 Commandlet。
本地 UE5.6 源码显示 OnSetSkeleton 会走 WaitOnExistingCompression(false) 的取消分支。
隔离模式改为先 WaitOnExistingCompression(true)，再绑定并保存新动画，两次重试均正常退出。
API 参照 [Epic UAnimSequence](https://dev.epicgames.com/documentation/unreal-engine/API/Runtime/Engine/UAnimSequence)；具体取消与完成行为以本地 UE5.6 实现和本轮运行结果为准。
没有修改 Engine、生产压缩设置或正式 Skeleton。
