# Rifle 第一人称可附身调试蓝图

日期：2026-10-10。环境：UE 5.6.1。本轮为隔离实验控制与视角封装，不提交 Git。

## 使用方法

打开 `/Game/Experiments/RifleTransition/L_RifleTransition_FirstPerson_Test`。
点击 Play（Selected Viewport 或 New Editor Window），点击游戏画面取得输入焦点。
关卡中的 `BP_RifleTransition_DebugPawn` 会自动由 Player 0 附身，默认第一人称。
不要用 Simulate 作为进入第一人称的步骤。

| 按键 | 操作 |
| --- | --- |
| 1 | ArmedAim／LowReady 目标切换；过渡途中再次按可反向 |
| 2 | 俯仰依次为 0、30、60、-30、-60，再回到 0 |
| 3 | 混合强度循环 0、0.5、1；初始 1，首次按为 0 |
| V | FP／TP 外部观察视角切换 |
| 鼠标 | 调整视角，俯仰限制为 ±60° |
| Shift+F1 | PIE 释放鼠标，再点击游戏画面恢复输入 |
| Esc | 结束 PIE |

左上角持续显示视角、IK OFF、实际 WeaponAction 状态、目标、Pitch、Mask、
Transition Player 时间、播放方向和最后操作。
目标先变化、实际状态后变化是正常过程，HUD 没有把目标当作当前状态。
ArmedAim 的 Player 时间可能保留或归零；该字段只描述过渡 Player，不是状态持续时间。

蓝图和专用 GameMode 可在 Content Browser 的实验目录中查看。
控制功能由 Editor 模块的原生 Pawn 提供，蓝图是可放置和附身的实例类。
蓝图公开 `ToggleGoal`、`CyclePitch`、`CycleStrength`、`ToggleView` 和 `GetDebugText`。
本轮资产只用于未烹饪的编辑器实验，不作为正式可打包角色。

## 实现范围

新增三个资产：

- `BP_RifleTransition_DebugPawn`：独立 APawn，默认 Auto Possess Player 0。
- `BP_RifleTransition_DebugGameMode`：原生 PlayerController，无默认生成 Pawn。
- `L_RifleTransition_FirstPerson_Test`：复制既有环境，用新 Pawn 替换静态预览 Actor。

Pawn 用 ChildActorComponent 组合既有 `AShooterRifleTransitionPreview`。
复用原 TP 实验 AnimBP 和 FP CopyPose 网格；不重做动画图、不增加 IK。
原 `L_RifleTransition_Test`、生产和实验动画、Skeleton、Reload 遮罩均保持原样。

只修改三份既有 Editor 源码：夹具 `.h`、`.cpp` 和 `ShootGameEditor.Build.cs`。
添加实验 Pawn、按键、HUD，并加入私有 InputCore 依赖；未新建源码或模块。
因此不需要刷新 VS 工程文件。
屏幕信息和 FP 视图更新只在本地受控 Pawn 执行，未接入 Gameplay 或复制。

### 第一人称相机

相机沿用生产角色的 head Socket、相对位置 `(-2.8, 5.89, 0)`，
初始相对旋转 `(0, 90, -90)`、FP FOV 90° 和 FP Scale 0.6。
本地相机方向来自 Pawn 控制器，避免直接叠加 head 骨骼旋转。
相机位置仍继承 head 的实际位置；没有在本轮加入头部位置稳定方案。
FP 网格与 FP 枪械启用 FirstPerson Primitive，TP 网格与枪械在 FP 中对拥有者隐藏。
Near Clip 为实验值 1 cm。

本轮提供的是项目相机参数与真实实验姿态的观察入口。
未接入正式 ShooterCharacter 的完整 FP 专用数据、Gameplay 或相机修正流程。
实际截图中，极端上仰仍有明显枪械遮挡；这不是已经验收的最终游戏画面。
保持 IK 关闭，也没有为消除遮挡修改动画或权重。

依据 [Epic 玩家相机示例][epic-camera] 使用 Pawn 的自动附身和输入绑定。
本地 UE 5.6.1 `Pawn.h` 确认 `AutoPossessPlayer` 与 `SetupPlayerInputComponent`。
`CameraComponent.cpp` 的控制器旋转分支要求相机 Owner 是 Pawn。
既有相机 Owner 是 Preview Actor，因此包装 Pawn 的 `CalcCamera` 显式采用控制器朝向。
这是本地组合夹具与官方直接在 Pawn 上创建 Camera 的差异。
