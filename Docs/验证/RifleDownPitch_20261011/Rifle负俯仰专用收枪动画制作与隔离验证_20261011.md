## 用户自行视觉验收

1. 打开上述 L_RifleDownPitch_Compare，用 World Outliner 标签区分三个 Actor。
2. 使用 Simulate，让编辑器保持可选 Actor；所有候选默认 -30°、Mask=0、IK 关闭。
3. 对 Baseline 与 Down30 使用详情中的 Toggle Rifle Test Goal，比较收枪与抬枪。
4. 分别选取 Actor，用 Cycle Rifle Test Pitch 切到 -60°，比较 Baseline 与 Down60。
5. 降枪开始约四分之一、二分之一、四分之三处再次 Toggle，检查中途反向。
6. 用 Cycle Rifle Test Natural Pitch Strength 切到 1，重复负俯仰对照。
7. 0° 只验现有 Baseline 的回归；新候选固定错角播放不代表自动俯仰混合。

Cycle Pitch 的旧顺序为 0、30、60、-30、-60；本轮只验 0、-30、-60。
用这些按钮改变运行中目标，避免直接修改详情属性引发 Actor 重建。
多 Actor 操作难以保持同帧时，可先逐个观察，再参考固定同帧截图与曲线。
主要看枪口是否绕到水平、右腕是否扭转、肩肘是否僵硬，以及共同低位衔接。
本地图是源动画对照夹具，没有动态混合控制器，也不是可玩 Gameplay 场景。
