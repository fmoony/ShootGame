# Rifle -50° 分段方案验证（2026-10-11）

## 范围与实现

按用户要求将 Down60 起用阈值改为 -50°，只创建新隔离方案。
严格规则为 P < -50° 用 Down60、-50° ≤ P ≤ -30° 用 Down30，其余用 CorrectedGrip。
正负号不变；-50° 本身仍为 Down30。
沿用 ArmedAim ↔ AimTransition ↔ LowReady 三态图与同一素材反向播放。
只在离开稳定状态时选片；活动过渡中的反向或俯仰变化不换片、不重置时间。
没有重新制作 Blender / FBX，没有修改动画关键帧、IK 或 Blend Mask 权重。

## 实测结果

Editor 构建成功；新 AnimBP 编译和独立地图保存成功。
实际 UE AnimGraph 固定 60 Hz，IK 关闭，Natural Pitch 强度分别为 0 和 1。
15 个输入角度覆盖 0、正俯仰、-30°、-50°、-60° 两侧和 -75°。
全程降枪 / 抬枪、25% / 50% / 75% 中途反向及活动过程中改变俯仰合计 126 用例。
32,760 帧的选片、活动期锁定和时间步长检查通过，违规数为 0。
所有用例最终回到 ArmedAim；完整往返用例实际经过 LowReady。
姿态数值有限，右手、左手、右肩臂、spine_05 和 Muzzle 均有逐帧记录。

以下为 Mask 0、Full 用例，坐标统一到 Body Component Space。
入场步长比较第 59→60 帧，最大枪口步长覆盖第 60–219 帧。
旋转使用 Muzzle 四元数最短夹角，右手使用 Component Space 位置距离。
最大步长包含返回 ArmedAim 的状态混合，不能解释为纯片段自身关键帧误差。

同样 -60° / Mask 0 / Full，旧方案选 Down30，新方案选 Down60。
入场枪口步长从 2.407020° 降至 0.013000°。
最大枪口步长从 7.892866° 降至 3.026638°。
这说明该输入下的端点匹配改善，不证明所有俯仰下的完整视觉自然度。

正常抬枪累计时间从 0.833333313 秒到 0.816666663 秒。
50% 中途反向从 0.416666806 秒到 0.400000125 秒，素材保持不变。
动画时长、播放倍率和时间方向沿用原夹具。

## 视觉取证与手动验收

有限视口取证覆盖 -49.999°、-50°、-50.001°、-55° 的 Mask 0，以及 -50.001° 的 Mask 1。
每组保存 ArmedAim、早期收枪、中段、LowReady 与反向中段，共 25 张截图。
地图对照 Actor 固定 CorrectedGrip，新方案 Actor 动态选择 Down30 / Down60。
截图位于 Saved/RifleSegmented50_20261011/Screenshots，capture.json 记录状态与选片。
该记录用于可复核姿态取证，不构成完整 Gameplay 视觉验收。

打开新地图，选择 Segmented50 LowToReady Actor，运行 Simulate。
用 Cycle Segment Pitch 依次观察 -45、-50、-50.01、-55、-60。
用 Toggle Rifle Test Goal 验收降枪、抬枪及中途反向。
先观察 Mask 0，再用 Cycle Rifle Test Natural Pitch Strength 比较 Mask 1。
重点观察 -50° 两侧的肩臂、双手握持和首尾衔接；不要只看静态首帧。

严格选片边界仍存在素材差异，没有增加跨片混合或阈值迟滞。
过渡中改角度虽然保持素材和时间，回到 ArmedAim 时仍可能有较快的姿态追赶。
-29.999° 继续使用原动画，其既有折返问题没有被本次阈值调整解决。
人工自然度与完整 Gameplay 视觉验收仍待用户判断。
