# 审计 Commandlet 递归覆盖状态机子图

- 日期：2026-08-25
- 计划提交说明：`动画资产：审计 Commandlet 递归覆盖状态机子图`
- 变更类型：Editor 工具

## 目的

R6.3 数据迁移必须逐项对比 EventGraph、AnimGraph 以及状态机内部状态图和 Transition 图中的变量来源。上一版审计 Commandlet 只遍历顶层 Graph 数组，会漏掉 `AnimGraphNode_StateMachine` 的 `SubGraphs`。本提交补上递归遍历，让 `LocomotioStateMachine`、FPP_* 状态图和 `AnimationTransitionGraph_*` 全部进入同一份审计证据。

## 本提交完成内容

- `ShooterAnimBPGraphAuditCommandlet` 增加 `SubGraphs` 递归与 `VisitedGraphs` 去重。
- 审计输出覆盖四个目标 AnimBP 的全部子图；仍只读，不 MarkPackageDirty、不保存资产。

## 验证结果

- `BuildEditor.ps1`：Passed。
- Commandlet 运行：`AUTOMATION_ANIMBP_GRAPH_AUDIT_SUMMARY Total=4 Failures=0`，引擎退出码 0。
- 新覆盖的子图包括：
  - TP Rifle / Pistol 的 `LocomotioStateMachine`、`FPP_Idle`、`FPP_Run`、`FPP_JumpStart/Loop/End`、`AnimationTransitionGraph_213～219`。
  - FP 资产无状态机子图。
- 日志：`Saved/Automation/AnimBPGraphAudit.log`；节点/连接摘要同目录 `.nodes.txt` / `.links.txt`。
- 本提交不涉及 `.uasset` 修改。

## 遇到的问题

- UE5.6 中 `UBlueprint` 无公开 `GetAllGraphs` 辅助函数；第一次递归实现还遇到 `TArray<const UEdGraph*>` 与 `SubGraphs` 指针 const 性不一致，改为在非 const `UEdGraph*` 上遍历后编译通过。

## 处理方式

- 只提交工具改进；R6.3 的资产节点迁移继续等待明确放行。
