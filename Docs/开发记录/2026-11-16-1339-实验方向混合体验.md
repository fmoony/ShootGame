# 实验方向混合体验

- 日期：2026-11-16
- 计划提交说明：配置：开启实验方向输入平滑供实际体验
- 变更类型：实验资产 / 文档

## 目的

WASD 原先只命中八向点，启用方向过渡以体验相邻动画混合。

## 本提交完成内容

仅将 BS_SourceLayer_Lower 的 Forward、Right Smoothing Time 从 0 改为 0.2 秒。
保留原 Spring Damper、Damping Ratio=1、Weight Speed=0。
九个样本及动画文件没有修改，未增加 C++ 或动画求解。

## 验证结果

MCP 读回两个轴为 0.2，保存成功，样本数组与修改前完全一致。
已启动可见 UE 5.8 PIE，切为外部视角，保持手动控制。
仅做参数和启动验证，没有重跑整圈接触测试，已知穿地未修复。
修改前后参数见 Saved/StanceBlendPreview_20261116。

## 遇到的问题

无新增工具错误；原配置的输入平滑时间为零，切换方向不会渐进经过中间位置。

## 处理方式

使用现有原生 BlendSpace 轴输入平滑，仅保存指定实验资产。
依据 Epic Blend Spaces 的 Smoothing Time 定义，并核对编辑器实际属性。
[官方说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/blend-spaces-in-unreal-engine)。

## 遗留项

动作自然度与过渡手感待用户体验，鞋底及相邻方向穿地仍存在。
