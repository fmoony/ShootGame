# 收尾第三人称瞄准与左手 IK

- 日期：2026-08-27
- 计划提交说明：`动画：收尾第三人称瞄准与左手IK`
- 变更类型：生产代码 / 测试 / 文档 / 资产 / 构建

## 目的

收拢 Rifle 左手握持、第三人称瞄准同步和贴墙近点稳定性改动，解决观察端快速或缓慢改变俯仰时枪支与手臂发生跳变、近点反馈振荡，以及采用固定参考枪口后瞄准精度明显下降的问题；同时保存本轮已经完成的 AnimBP 连线、资产调整、诊断工具和计划归档。

## 本提交完成内容

- `FAnimNode_ShooterAimIK` 增加世界目标点模式：使用进入节点的预 Aim IK `hand_r` 与缓存的 `HandToMuzzle` 还原预 IK 枪口，再从该枪口指向表现目标；保留基础视线模式作为本地拥有者和无效目标回退。
- `UShooterThirdPersonAnimInstance` 提供 `AimTargetWorld` 与 `bAimTargetWorldValid`，保留视点和枪口前方安全距离，且不再逐帧读取 Aim IK 完成后的实时枪口作为下一帧求解输入。
- 保留并收尾左手 IK 数据与节点链路：Rifle 使用 `Aim IK → Left Hand IK`，左手消费校准后的握把参考帧；Pistol 复用 Aim IK，但不强制启用 Rifle 左手握持。
- 更新 `ABP_TP_Rifle` 与 `ABP_TP_Pistol`：连接 `AimDirectionWorld`、`AimTargetWorld`、`bAimTargetWorldValid` 和 `HandToMuzzle`；Rifle 继续连接左手 IK 所需数据和 Alpha 开关。
- 纳入 `ABP_FP_Weapon`、`ABP_FP_Pistol` 的当前已保存调整，以及 `BP_ShooterWeapon_GrenadeLauncher`、`SK_GrenadeLauncher` 的用户现有资产改动。
- 扩展 `ShooterNetworkTestCoordinator` 的转向/近墙 CSV 诊断，记录目标、实时枪口、最终骨骼姿势、参考方向和残差；节点诊断只在 `-ShootGameAimTurnCsvTest` 下启用。
- 扩展 `RunNetworkSession.ps1`，支持渲染客户端、可见客户端和并行客户端启动，便于自动评估真实 AnimGraph 骨骼结果。
- 将 `ShootGameEditor` 调整为 `UncookedOnly / PreDefault`，并使用 `GameUncookedOnly` 包类型，使未烹饪的 `UnrealEditor -game` 客户端能够加载自定义 AnimGraphNode 外壳；烹饪后仍只保留 Runtime AnimNode。
- 增补 Aim、左手握把参考帧、缓存刷新和稳定 Pole 相关 Automation 覆盖。
- 将 `Rifle左手IK与瞄准同步提速实施计划.md` 移入 `Docs/已完成计划/`，同步更新表现规划导航，并保留贴墙收尾计划的暂缓状态说明。
- 纳入本轮已有的代码格式与注释调整，包括 Equipment 和 Left Hand IK 的排版变化。

## 遇到的问题

- 未烹饪 `UnrealEditor -game` 客户端最初无法加载自定义 AnimGraphNode 的 Binding，运行时 AnimGraph 只剩 Root 与 ComponentToLocal，导致早期 CSV 不具备验证价值。
- 一次联机会话漏传 `-ShootGameNetworkTest`；随后沙箱内客户端又因用户 Shader/DDC 缓存目录不可写而退出。
- 初版直接使用上一帧 Aim IK 后的实时枪口重新计算下一帧方向，形成逐帧正负反向修正的反馈环。
- 临时改用 Mesh 空间固定参考枪口后反馈振荡消失，但近点瞄准方向与实际基础姿势枪口不一致，产生明显精度损失。
- `.uasset` 为二进制资产；GrenadeLauncher 两个用户现有资产改动没有在本轮单独反推其内部属性差异。

## 处理方式

- 将 GraphNode 所在模块从 `Editor` 改为 `UncookedOnly`，并在独立客户端日志中确认自定义 Aim/Left Hand 节点被遍历和执行。
- 修正联机测试参数，并在获得允许后让 UE 在沙箱外写入自身 Shader/DDC 临时目录，完成真实渲染客户端验证。
- 用 CSV 对比实时枪口反馈方向和固定参考方向，确认振荡来自最终姿势反向进入下一帧求解。
- 放弃固定参考枪口作为最终方案，改为在 `FAnimNode_ShooterAimIK` 内从输入 Pose 计算预 IK 枪口，再对世界目标点求方向；由节点自身完成枪口前方安全投影。
- 通过人工蓝图连线把 `AimTargetWorld` 和 `bAimTargetWorldValid` 接入 Rifle/Pistol Aim IK，并以最终视觉验收确认精度和稳定性。
- GrenadeLauncher 资产按用户明确要求随全量提交保留，不对二进制内容作无证据描述。

- `ShooterNetworkTestCoordinator` 中的转向 CSV 与 AnimNode 诊断属于本轮排障工具，当前按用户要求一并提交；稳定后可单独评估是否瘦身或移入专用 Debug 文件。
- 大范围快速甩枪时的网络表现延迟仍属于后续瞄准同步策略问题，本提交只消除本地姿势反馈振荡，不改变服务器权威和现有网络平滑频率。
