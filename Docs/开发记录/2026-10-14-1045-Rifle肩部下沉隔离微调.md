# Rifle 肩部下沉隔离微调

- 日期：2026-10-14
- 计划提交说明：`实验：微调 Rifle LowReady 肩位并保留头部端正方案`
- 类型：实验资产／Editor 验证工具／文档
- 本轮不提交，等待用户视觉验收。

## 目的与完成内容

将 clavicle 局部旋转向 ArmedAim 参考靠近的比例从 18% 增加到 35%。
制作 LowReady 和配套 CorrectedGrip 副本，逐帧协调手臂以保持原手部目标。
三份新 AnimBP 均保留 HeadUpright，仅更换肩部动画引用。
新地图复用真实角色与游戏控制器复制体、Debug、K 正反和 F8 脱离。
已有 Editor 夹具增加新路径、-30° 和骨骼取证，不修改任何动画求值算法。

## 验证结果

- Blender／FBX 往返通过，原长度、采样率与关键帧数量保持。
- ShootGameEditor Development 编译成功。
- 72 组、21,600 帧实际图数值对照通过，12 组新方案中途反向通过。
- 胸腔坐标中的新增肩高：左约 1.09 cm，右约 1.61 cm。
- ArmedAim 与受测头颈、脊柱变换差为零。
- 双手最大数值位移增量 0.522 cm，新增状态边界步长小于 0.046 cm。
- 真实角色四角度、正反五阶段共 120 张 FP／TP 图及 60 视点。
- 最终 PIE 回归 Success，零错误、一条既有 GAS 路径警告。
- 相机朝向保持，最大视点采样差约 0.23 mm，包含基线采样差。
- 原握持关系基本保持；仍需用户自然播放视觉验收。
- 1,108 个既有文件仅两份 Editor 夹具源码允许变化，历史材料和生产保持。
- 增量文本版式、包含路径和 Git 空白检查通过。

## 遇到的问题与处理

- 新夹具遍历 TObjectPtr 时使用 auto* 推导失败，改为显式 UEdGraphNode*。
- 取证局部变量 Id 遮蔽截图 Id，改为 BoneId，最终编译通过。
- Python Skeleton 属性只读，复用原生 SetSkeleton 并核对全部骨名／父索引。
- 首次渲染受沙箱 Shader 目录写入限制而退出，必要权限重跑同一隔离测试通过。
- +60° ArmedAim 左肩参考显著提高，不追求固定 LowReady 素材完全重合，避免耸肩。
- 原 Raw 端点有素材相位差，以真实图连续采样和旧版增量判断边界。

## 遗留项

用户验收肩位与放松感、完整 Idle 循环、动态俯仰、快速反向和 FP 可见性。
没有授权生产合并，没有执行新的网络、Reload／Fire 专项回归。
Editor 节点仍是隔离原型；正式头部落地和工具整理不属于本轮。
