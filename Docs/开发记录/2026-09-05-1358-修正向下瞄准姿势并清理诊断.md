# 修正向下瞄准姿势并清理诊断

- 日期：2026-09-05
- 计划提交说明：`动画：修正向下瞄准姿势并清理诊断代码`
- 变更类型：生产代码 / 测试 / 资产 / 构建

## 目的

解决 Rifle 第三人称向下瞄准时左手腕变细、手臂姿势异常的问题，并在确认根因属于 Aim Offset 向下样本后，移除本轮定位产生且不再需要的运行时诊断入口和诊断数学代码。

## 本提交完成内容

- 新增并接入修正后的 Rifle 向下瞄准样本 `MM_Rifle_Idle_ADS_AO_CD_Fixed`，更新 `AO_Rifle` 与 `ABP_TP_Rifle` 的相关资产配置。
- 清理被替代的 Rifle Aim 样本和第三人称 Aim Control Rig 资产。
- 纳入当前第一人称 Rifle AnimBP、手部调整 Rig、武器与弹丸蓝图及测试地图的阶段性资产改动。
- 删除临时控制台变量 `ShootGame.LeftHandIK.Enabled`、`ShootGame.LeftHandIK.Diag` 和 `ShootGame.ThirdPersonAnim.AimPitchOverride`。
- 删除只服务本轮排查的手腕 Swing/Twist 数值诊断、日志、辅助数学与对应自动化测试；保留正式左手 IK、握把 Transform、Pole 稳定逻辑及原有核心测试。

## 验证结果

- 用户人工 PIE 验收：替换向下瞄准样本后，原有向下俯仰手腕异常已解决。
- `Scripts/Tests/BuildEditor.ps1`：通过，`ShootGameEditor Win64 Development` 构建成功。
- `Scripts/Tests/RunAutomation.ps1 -TestFilter ShootGame.Aim.LeftHand`：通过，3 Passed / 0 Warning / 0 Failed。
- 未执行完整联机与全项目 Automation；本提交的自动验证范围集中在编译和左手 IK 核心数学回归。

## 遇到的问题

- 最初现象在启用或关闭 LeftHand IK 时均可能出现，容易被误判为 IK 末端旋转、Grip Socket 或网络同步问题。
- 使用固定 AimPitchN 分段验证后发现，仅 `-1` 和 `-0.5` 区间异常，而 `0` 与正俯仰区间正常。

## 处理方式

- 使用临时 CVar 分别绕过 LeftHand IK 并固定 Aim Offset 输入，隔离 IK、网络数据和动画样本的影响。
- 根据负俯仰端点可稳定复现、中心及正俯仰正常的结果，将根因收束到向下 Aim Offset 样本，并通过修正资产解决。
- 根因确认后删除整套临时诊断链，避免一次性排错代码长期留在运行时和测试模块中。
