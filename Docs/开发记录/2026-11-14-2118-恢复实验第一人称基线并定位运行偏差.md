# 恢复实验第一人称基线并定位运行偏差

- 日期：2026-11-14
- 计划提交说明：动画：恢复实验第一人称基线并增加运行变换诊断
- 变更类型：Editor 测试 / 脚本 / 文档

## 目的

取消 Stance 实验历史眼点和双肩迁移，按正式角色的实际实现建立对照。
通过实际运行骨骼、相机及枪械数据定位剩余偏中、贴枪和极端俯仰差异。

## 本提交完成内容

- 删除独立眼点前移及 47 cm 双肩迁移，采用附着 FP head 的 CameraComponent。
- 读取正式 BP_ShooterCharacter 的实际相机参数和完整 FP 网格，不使用裁切双网格叠加。
- FP 在本帧 TP 所有既有处理完成后复制姿态；不改 TP 求值算法。
- 新增 CaptureView 与 analyze_view.py，保存各处理阶段及实际组件变换。
- 更新当前专题说明，新证据独立保存，不回写历史记录。
- 仍为 PoseableMesh 夹具，未移植完整正式 AnimBP、Montage 或网络角色。

## 验证结果

- 最终 Editor 构建成功，使用 UsePrecompiled、NoEngineChanges 与 NoUBA。
- 原实现与最终实现分别采集 108 场景、2,160 个采样帧，固定 60 Hz、每六帧记录。
- 最终 FP 与 Body 位置差为 0，旋转差小于 0.000004°。
- 前后 Body 位置差为 0，旋转差小于 0.000004°，实际 Body 与 final 阶段一致。
- 正式 head 局部相机偏移、FOV=90 与 Scale=1 已由实际运行读回。
- 最终六张 D3D12 截图仅用于补充几何观察，不代替数值证据。
- 21 项原保护资产哈希仍一致；未保存或改写 UE 资产。
- include、脚本语法、文本版式与 diff 检查通过，真实暂存区未改，未提交。
- 版式四条尾参数警告已人工核对，未放宽 120 / 140 列规则。
- 没有新建、删除或移动 C++ 源文件，不需要刷新 VS 工程。

## 遇到的问题

- 原实现没有受控 FP 枪械变换基线，先增加诊断并构建、采集原行为。
- 分析器初版把 BeginPlay 的 case=-1 当正式场景，完整性断言失败。
- 初次 Python AST 检查使用系统默认 GBK 解码 UTF-8 中文，产生解码错误。
- 新增 C++ 参数列表有版式问题，门禁正确失败。
- 版式日志最初未落盘，首次归档失败，改用独立 PowerShell 输出重定向后补齐。
- 恢复位置后裁切 FP 双网格仍不等同于正式角色的完整单网格。
- 固定位置补偿取消后，原始头肩关系和俯仰范围差异暴露，视觉并未完整通过。
- 引擎仍有既存 StateTree 弃用、IncludeOrder 和辅助 SDK 提示。

## 处理方式

- 基线、位置恢复中间版本及完整网格最终版本分开保留于 Saved。
- 初始化样本保留原始数据，分析仅比较输入已设定的 108 个场景。
- AST 检查显式使用 UTF-8，分析器控制台也显式输出 UTF-8。
- 修正版式后重跑门禁与构建，不放宽检查器。
- 从正式角色默认对象读取 FP 网格，移除实验显示用腿组件，历史派生资产保留。
- 分阶段记录证明锁骨未被持枪恢复移动，且 FP 最终复制无偏差。
- 记录相机与受限脊柱俯仰范围，以及实际枪口视线夹角，不增加位置补偿。

## 遗留项

- 平视蹲姿右手骨骼约在眼点后 1.13 cm，枪械挂点前向距离仅约 6.06 cm。
- 枪械挂点右向距离由站立约 11.31 cm 降为蹲姿约 1.28 cm。
- 实验未接正式上身分层与 ShooterAimIK，极端俯仰仍存在明显方向差异。
- 视觉遮挡、原素材头肩关系及自然度未标为通过。
- 踮脚、启停穿地、正式生产与网络接入继续保留边界。
