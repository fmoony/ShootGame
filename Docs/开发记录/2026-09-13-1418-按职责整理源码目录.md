# 按职责整理源码目录

- 日期：2026-09-13
- 计划提交说明：`结构：按职责整理框架武器与测试源码目录`
- 变更类型：生产代码 / 测试 / 文档 / 构建

## 目的

将 GameFramework、Weapons 与 Tests 中的平铺源码按稳定职责归类，取消含义过宽的
Weapons/Runtime 目录，同时保持现有 Gameplay 行为和系统依赖关系不变。

## 本提交完成内容

- 将 GameFramework 类按 GameMode、GameState、PlayerController 与 PlayerState 归类。
- 将武器配置、开火行为、持有者接口、拾取、弹丸、动画 Notify 与运行时子系统按职责归类，
  并将 ShooterWeapon 保留为 Weapons 根目录的领域主体。
- 将 ShooterAimMath 移入 Characters/Aim。
- 将 Tests 根目录的 Aim、Animation、Ability 与 Weapon 测试归入对应功能域，并将 Pool 测试
  合并到 Tests/Weapon。
- 更新迁移所必需的 include 路径、源码注释和 AGENTS.md 项目导航。
