- 日期：2026-08-25
- 计划提交说明：`GAS：Ability 改用 Tag 与 Equipment 边界`
- 变更类型：生产代码

## 目的

执行《Shooter 核心玩法架构解耦重构执行计划》R5：GA_Fire / GA_Reload / GA_Equip 不再通过 Cast Character/NPC 判断死亡，统一改用 ASC `State.Dead`；当前武器统一从 EquipmentComponent 读取，Inventory 只承担弹药、槽位与目标查询。

## 本提交完成内容

- `GA_Fire`：
  - 服务器 CanActivate / Activate 的死亡判断改为 `ASC->HasMatchingGameplayTag(State.Dead)`；
  - `GetCurrentWeaponForAvatar` 改为 Equipment 优先、`IShooterWeaponHolder` NPC 兼容回退；
  - 删除 GetShooterCharacter / GetShooterNPC 与 ShooterNPC include。
- `GA_Reload`：
  - 死亡判断改用 State.Dead；
  - CurrentWeapon 从 Equipment 读取；
  - ActiveWeaponInstanceId 从 Equipment 读取，弹药/容量继续读 Inventory。
- `GA_Equip`：
  - 死亡判断改用 State.Dead；
  - NextSlot 起点、PreviousInstanceId、提交前 CurrentWeapon 与 Active 校验全部改读 Equipment。
- 保留 ServerOnly、Cooldown/Cost/Tag 顺序与失败语义不变。
