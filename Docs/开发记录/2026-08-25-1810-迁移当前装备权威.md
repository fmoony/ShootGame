# 迁移当前装备权威

- 日期：2026-08-25
- 计划提交说明：`装备：迁移当前装备权威`
- 变更类型：生产代码 / 测试

## 目的

执行《Shooter 核心玩法架构解耦重构执行计划》R4：把 `ActiveWeaponInstanceId` 与 `CurrentWeaponActor` 从 Inventory / Character 迁入 `UShooterEquipmentComponent`，使“当前装备”只有一个写入方，并让服务器、拥有者客户端与观察者最终收敛到同一 CurrentWeaponActor。

## 本提交完成内容

- `UShooterEquipmentComponent`：
  - 启用组件复制；`CurrentWeaponActor` 复制给所有观察者，`ActiveWeaponInstanceId` OwnerOnly；
  - `EquipWeapon` 执行 Deactivate / 身份与实体原子赋值 / Attach / Activate / AnimClass / Event / AimReset / ForceNetUpdate；
  - `ClearEquippedWeapon`、`HandleWeaponActorReady`、Inventory Remove/Clear 通知收敛；
  - OnRep 与服务器本地修改共用幂等 `ApplyCurrentWeapon`。
- `UShooterInventoryComponent`：
  - 删除 `ActiveWeaponInstanceId` UPROPERTY、SetActive 写入口与 OnRep；
  - 新增 `OnWeaponInstanceRemovedFromInventory` / `OnInventoryCleared` 事件；
  - 保留 R4 迁移期只读 Getter，转发 Owner Equipment。
- `AShooterCharacter`：
  - 删除 CurrentWeapon 复制属性、OnRep 与 ApplyCurrentWeapon；
  - `GetCurrentWeapon` / `GetCurrentWeaponActor` 转发 Equipment；
  - `CommitActiveWeapon` 变为兼容转发，Death/EndPlay 使用 Equipment 当前值并依赖 Inventory Clear 事件清空。
- `AShooterWeapon`：玩家武器不再在 InitializeWeaponOwner 自动 Attach；Owner/BoundInstanceId 晚到时通知 Equipment 幂等补做；NPC 保留原兼容路径。
- 测试：Inventory / Architecture / GA_Equip 契约测试改为 Equipment 字段预期；网络协调器的 InvalidInstance 测试改走 Equipment。

## 遇到的问题

- 写入 Equipment cpp 时 heredoc 被截断，`GetNameSafe` 变成 `GetNameS\nafe`，首次 R4 编译失败。

## 处理方式

- 读取损坏行并补全为完整 `*GetNameSafe(PreviousWeapon)`；重新编译通过。
