- 日期：2026-10-16
- 计划提交说明：`玩法：接入预测走跑与自动收枪并保持即时射击`
- 变更类型：生产代码 / 测试 / 文档
- 工作基线：GitHub origin/main 与本地均为 38be3be，开始时工作区干净。
- 本轮不创建 Git 提交、不推送远端；记录随改动保留供审阅。

## 目的

把已验收 RifleReady 从 K 调试目标接入真实走跑。
默认行走持枪，按住 Shift 跑步收枪，开火立即退出跑步并抬枪。
继续使用现有 GA_Fire 即时 Shot，不等待动画、不补枪。

## 本轮完成内容

- 新增 ShooterCharacterMovementComponent，替换角色默认 CMC。
  Walk 250 / Sprint 600 cm/s 可配置，保留原生移动物理、位置复制与网络平滑。
- FShooterSavedMove 用 Custom_0 / Custom_1 保存 Shift / Fire Held。
  按键边沿不能合并，历史输入随纠正重放，结束后恢复当前真实意图。
- 服务器独立检查地面移动、Fire Held、权威输入镜像与动作标签。
  实际 Sprint 只向 Simulated Proxy 复制；服务器动作阻塞另向 Owner 确认。
- Enhanced Input 的独立上下文以优先级 1 消费 LeftShift，覆盖原 Shift 切枪映射。
  滚轮切枪不变；Completed / Canceled、死亡、失去占有与 EndPlay 清理意图或映射。
- Fire 输入先退出 Sprint，再按原 ASC / GA_Fire 链路执行。
  GA_Fire 激活只额外刷新 Sprint，原预测预算、节拍与 Commit 路径不变。
- 正式 AnimInstance 使用 Sprint 目标，复用 RifleReady 的原始播放器和图结构。
  Local 分层、头颈修正、IK、±1 播放及中途反向不变。
  正式 Fire 使用反向抬枪，独立 K 预览才保留原 Montage 硬中断。
- 默认关闭 K，显式 DebugPreview 模式才允许旧调试入口。
  原 K 自动化测试显式开启并恢复模式，生产 Gameplay 不调用 Toggle RPC。
- 保留 Pistol 原持姿；Rifle、AWP、GrenadeLauncher 继续使用现有 LowReady 支持名单。
- 新增 SavedMove 规则测试、真实 Dedicated NetDriver 双客户端与延迟丢包 Gameplay 测试。
  不保存修改任何 uasset 或生产地图，不修改 Projectile、伤害与弹药预测代码。
- 修正旧 Coordinator 的 Fire-after-Reload 门槛：记录真实激活增量，要求恰好一次。
  保留原 Projectile、Ammo 和静默收敛检查，生产 Ability 不为测试保持活动。

## 按契约标题含义的不变量覆盖确认

### Invariant 1 Owner Immediate Feedback

- 触及：Fire 输入先退出 Sprint，再进入即时 Intent 和本地反馈。
- 不应改变：Intent / Presentation / Authority 分离，确认不补播历史反馈。
- 新证据：抬枪未完成时已发生本地反馈与服务器 Shot。
- 范围外：反馈资源和听感调校；未更换反馈入口或素材。

### Invariant 2 Local Prediction Obeys Weapon Rules

- 触及：Fire Held、Reload、Equip、Dead 互斥，移动预测及纠正重放。
- 不应改变：武器节拍、预算、GAS 门控、不补枪及生命周期清理。
- 新证据：Held 期间不 Sprint，松开恢复，动作窗口阻塞，移动输入正确重放。
- 范围外：新增射击预测协议；继续由现有四路径回归取证。

### Invariant 3 Server Is Final Authority

- 触及：服务器自行判断速度、动作阻塞和实际 Sprint。
- 不应改变：Ammo、Projectile、Hit、Damage、Death、Score 权威入口。
- 新证据：动作阻塞、错误位置纠正、纯移动 Shot / Ammo 零增量。
- 范围外：伤害与弹丸算法；未进入这些实现，使用既有回归验证兼容性。

### Invariant 4 Remote Is Confirmed Only

- 触及：Observer 只从服务器复制 Sprint，驱动自己的正式 AnimBP。
- 不应改变：远端射击 Montage / Muzzle / Sound 确认来源。
- 新证据：独立 Observer 的实际速度和姿态随权威状态变化。
- 范围外：逐帧动画时钟同步；各端继续独立推进播放器。

### Invariant 5 Exactly One Authority Result

- 触及：Sprint / Fire 顺序不能引入重复提交、动画完成补枪或延迟补播。
- 不应改变：认可激活对应唯一 Commit、Ammo 消耗和 Projectile。
- 新证据：纯移动零增量，跑动开火 Shot / Ammo 增量一一对应。
- 范围外：Reload 事务重构；保留原实现并执行既有事务回归。

## 遇到的问题

- SavedMove 不是 UCLASS，没有隐式 Super 别名，首次编译失败。
- 编辑器测试直接调用 GAS Loose Tag 内联方法遇到模块链接符号缺失。
- 临时输入诊断误用受保护方法，随后又引入编辑器模块未链接的 EnhancedInput 符号。
- 最初隔离地板是各世界独立匿名组件，服务器 MovementBase 无法在客户端解析。
- Shift 同时触发旧切枪，Rifle 场景被 Pistol 覆盖。
- 无延迟纠正没有未确认 Move 时不会重放，不能以重放次数替代纠正次数。
- ServerOnly Equip 标签未及时到达 Owner，客户端在服务器装备窗口内仍预测 Sprint。
- 完整网络入口停在 Fire-after-Reload：Shot 和反馈已经发生，旧持续活动门槛永远不成立。

## 处理方式

- SavedMove 显式声明基类别名，测试用真实权威伤害覆盖死亡。
- 移除临时跨模块诊断，使用已有公开 Core 日志和正式输入路径。
- 地板改为服务器复制且 AlwaysRelevant 的 StaticMeshActor，保持真实 MovementBase。
- Sprint 映射提高优先级，保留原输入资产与滚轮切枪。
- 分别记录收到纠正和实际 SavedMove 重放；延迟用例必须观察重放。
- 只在移动组件复制服务器动作阻塞结果，保留 Equip Ability 和 GAS 事务。
- 用现有 Ability 激活观察器冻结基线，要求实际增量恰好 1；大于 1 立即失败。
  之后原静默检查仍要求无活动 Fire、无 Firing Tag、无额外 Ammo / Projectile。
  Dedicated 两名玩家均达到 FeedbackDelta=1、ConfirmationDelta=1、Valid=true 后继续。
