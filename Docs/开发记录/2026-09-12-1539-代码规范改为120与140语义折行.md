# 代码规范改为 120 / 140 语义折行

- 日期：2026-09-12
- 计划提交说明：`规范：改为 120/140 语义折行并关闭 clang-format 自动断行`
- 变更类型：规范 / 开发脚本 / 配置

## 目的

旧规范把 120 列当硬门禁，并要求超限调用每参数一行，产生大量无意义竖排折行，损害阅读。
改为：120 列是常规边界，140 列是绝对上限；120～140 之间只允许
“最后一个参数（逐层到最深尾巴）”越界；参数列表优先一行、放不下则两行，
达到三行及以上时每个参数单独一行；注释严格 120；
URL 与资产路径作为不可拆单元豁免。

## 本提交完成内容

- 更新 `Docs/代码规范.md` 的“版式与换行”代码规则与增量门禁说明，
  Markdown 规则保持不变。
- 更新 `.clang-format`：`ColumnLimit: 0`，`BinPackArguments/Parameters: true`，
  增加 `AllowAllArgumentsOnNextLine` 与 `AllowAllParametersOfDeclarationOnNextLine`。
- 重写 `Scripts/Development/CheckTextLayout.ps1` 的宽度检查：
  - 注释行超过 120 失败（URL / 资产路径行豁免）；
  - 代码行超过 140 失败；
  - 120～140 按“逐层最后一个参数”自动判定；无法判定时输出黄色警告由人确认；
  - C++ / C# 反向检查冗余换行：能并为一行、能压为两行的多行拆分被标记；
  - 参数列表达到三行及以上时，未按“每参数一行”排布会被标记；
    整组均为本次修改行时失败，否则只作警告；
  - Markdown 检查逻辑保持不变。
- 未修改任何生产代码、蓝图、资产或其他历史文件。

  `k(A,B,C(a,b))` 的 b 可见 Pass / b 完全不可见 Fail、超过 140 Fail、
