# 移除旧模块资产引用与重定向

- 日期：2026-08-15
- 计划提交说明：`清理：移除旧模块资产引用与重定向`
- 变更类型：资产 + 配置

## 目的

执行 [GAS 接入前架构整理执行方案](GAS接入前架构整理执行方案.md) 阶段 4：清除项目模块从 `TP_FirstPerson` 改名为 `ShootGame` 后残留在资产 import 表中的旧模块引用，并移除 `DefaultEngine.ini` 中的全部兼容重定向。

## 本提交完成内容

- 清除 19 个资产包内的 `/Script/TP_FirstPerson.*` 旧模块引用，import 表重写为 `/Script/ShootGame.*`：
  - 12 个蓝图/数据资产：`BP_ShooterAIController`、`EQS_FindSnipingLocation`、`ST_Shooter`、`ST_Shooter_ShootAtTarget`、`BP_ShooterProjectile_Bullet`、`BP_ShooterWeapon_GrenadeLauncher`、`BP_ShooterWeaponBase`、`DT_WeaponData`、`BP_ShooterGameMode`、`BP_ShooterPlayerController`、`UI_Shooter`、`UI_ShooterBulletCounter`（`-run=ResavePackages -Map=...` 精确重保存）。
  - 7 个含旧引用的 ExternalActors 包（`/Game/__ExternalActors__/Variant_Shooter/Lvl_Shooter/...`）。
- 删除 `DefaultEngine.ini` 中 `[/Script/Engine.Engine]` 段的全部 6 条重定向（2 条 `ActiveGameNameRedirects` + 4 条 `ActiveClassRedirects`）。
- 重保存后 Content 目录扫描确认 `TP_FirstPerson` 引用为 0。

## 重保存数量与扩大原因

- 精确 `-Map` 重保存：12 个蓝图/数据资产。
- 7 个 ExternalActors 是 World Partition 外部包，无法通过 `-Map` 直接指定其哈希路径单独重保存；只能重保存主地图 `Lvl_Shooter` 级联处理。因此主地图级联重保存了 **144 个资产包**（12 蓝图 + `Lvl_Shooter.umap` + 137 个 ExternalActors/ExternalObjects 包），其中超出 19 个的部分为级联重新序列化（字节级规范化变化，无内容实质改动）。
- 未触碰 `CtrlRig_FPWarp.uasset`（执行前已存在的用户修改）。

## 验证结果

- 执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Tests\RunAll.ps1 -Port 17794`，在**无任何旧模块重定向**条件下七阶段（Build / Automation / Standalone / DedicatedNetwork / ListenNetwork / EmulatedNetwork / DisconnectCleanup）全部 Passed。
- 实际结果文件：`Saved/Automation/Runs/20260815_145754/Summary.json`，顶层 `status: Passed`、`error: null`。
- Automation 阶段 `ShootGame.Weapon.Configuration` 通过，证明武器蓝图（`BP_ShooterWeaponBase` 等）在无重定向时能正常加载。

## 遇到的问题

- 首次删除重定向后自动化在 Automation 阶段失败：`BP_ShooterWeaponBase` 的父类 import 仍为 `/Script/TP_FirstPerson.ShooterWeapon`，删除 `ActiveGameNameRedirects` 后无法解析。
- `-Map` 直接指定 7 个 ExternalActors 哈希路径时，ResavePackages 仅处理 12 个蓝图，ExternalActors 被跳过。

## 处理方式

- 保留重定向完成加载后，用 ResavePackages 重写 import 表，再删除重定向。7 个 ExternalActors 改用重保存主地图 `Lvl_Shooter` 级联处理。

## 遗留项

- `Config/DefaultEditor.ini` 为编辑器运行副作用，未纳入本提交。
- 本提交后 `Source/ShootGame/Variant_Shooter/` 已移除、旧模板类已删除、旧模块引用与重定向已清空，达到 GAS 接入前的架构基线。
