## 遇到的问题

- 初次审计缺少临时 GeometryScripting 插件加载，Python 类型不可用。
- Python 法线查询返回 tuple，初次离线正面判定绕序反向。
- Pistol 历史源模型有未引用顶点，验证日志存在相应告警。
- 初次 RenderData 检查未开启 commandlet rendering，缺少骨骼属性。
- Editor 保存锁与退出延迟，真实 RHI 冷缓存编译导致等待时间较长。

## 处理方式

- 补齐临时插件参数，按 UE5.6 实际返回值解包，并对照源法线纠正绕序。
- 保留原始顶点顺序和未引用顶点，不对历史几何做无关清理。
- 使用 AllowCommandletRendering 与 D3D12 重新读取真实 RenderData，通过后退出。
- 等待用户关闭 Editor 且残留进程退出后保存，不强制结束用户会话。
- 完整证据与保存边界见架构说明；Saved 中保留本机快照、报告和原资产备份。
