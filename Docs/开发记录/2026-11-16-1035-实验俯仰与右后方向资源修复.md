# 实验俯仰归一化与右后方向资源修复

- 日期：2026-11-16
- 计划提交说明：修复：实验原生俯仰映射并新增 Blender 右后方向输入
- 变更类型：Editor 夹具 / 动画资产 / Blender 源文件 / 验证脚本 / 文档

## 目的

修复原生实验鼠标俯仰快速顶到端点，以及八向右后前掌明显穿地。
保持生产代码和原始 Source，继续取消实验 C++ 动画骨骼处理。

## 本提交完成内容

- 通过 MCP 将 TP 的角度输入转换为 Sin(Degrees)，再连接生产 AO。
- Blender 制作三个右后扇区动作，保留后退原有局部曲线与全部骨骼高度。
- 标准 FBX 导入直接绑定生产 Skeleton；MCP 将三段加入实验 BlendSpace。
- 采集增加俯仰扫描、方向数量选项和真实 AO 值，C++ 不求解或回写骨骼。
- 更新原生图生成器、当前复测入口和实验现状，旧历史报告保留原貌。

## 验证结果

项目 BuildV2 成功；原生图、273 个保护文件及压缩导入核对通过。
11 个俯仰样本实际 AO 值误差小于 2.2e-8。
8 向两持枪采 1,840 帧；额外 32 向采 5,680 帧。
135° 前掌由约 -16.39 cm 改善为 +0.37 cm 以上；
112.5°～157.5° 的五个角度、两持枪状态均无超过 1 cm 的骨骼点穿地。
完整层和下半身位置一致，FP 世界位置复制误差为零。
数据和详细边界见验证报告 StancePitchBackRight_20261116。
源码包含路径、文本版式与 diff 检查通过；工作区未提交。

## 遇到的问题

旧零俯仰测试未覆盖角度与归一化坐标的差别。
BlendSpace 属性修改未刷新运行三角网格；打开编辑器重采样后若未标脏，
工具保存成功仍未更新文件。编辑器打开时重排数组又触发中间重复样本删除。
Editor 建图工具调用只接受动画节点的 BindInput 导致一次编译失败。

## 处理方式

增加非零输入和实际 AO、最终骨骼采集。
关闭资产编辑器后按顺序追加样本；打开原生编辑器重建，明确标脏并保存，
再从磁盘重载确认九个样本和运行接触结果。
将建图工具改成显式 VariableGet → Sin 调用，重新编译通过。
未恢复手工 C++ FK、混合、分层或 IK。

## 遗留项

本轮只修复八向目标中的右后及其扇区。
约 101.25° 仍有严重混合穿地；前向、左后和其他连续方向也未通过。
原 idle 仍是单膝跪姿，没有完成统一半蹲 idle。
鞋底平贴、脚滑、坡面、网络和完整生产 AimIK 接入未验收。
可视化 UE 5.8 PIE 已打开，需用户验收主观动作效果。
