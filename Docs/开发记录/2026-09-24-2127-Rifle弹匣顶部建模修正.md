# Rifle 弹匣顶部建模修正

- 日期：2026-09-24。

- 变更类型：资产 / 文档。
- 当前状态：已保存到原路径，独立进程重载验证通过；未提交。

## 目的

按当前工作区的新路径修正 Rifle 独立弹匣，移除灰色外翻边框和挂钩，
让黑色主体连续延伸到原顶部高度，并补齐顶面及全部开边。
本轮不调整整枪骨骼网格、其他武器或运行时代码。

## 本提交完成内容

目标资产：`/Game/Weapons/Rifle/Meshes/SM_Rifle_Magazine`。
该路径由磁盘文件与当前 Editor Asset Registry 双重确认，没有迁移或改名。

以下几何修改已通过 UE 资产系统保存，并由新的独立进程重载确认。

- 删除灰色上沿附属件 260 个三角面、挂钩附属件 134 个三角面。
- 保留主体和底部装饰原有 916 个三角面及其顶点位置、UV0 和法线。
- 从主体 14 点顶边向上延伸约 `0.3522 cm`，终点为原模型顶部高度。
- 新增 28 个侧壁三角面和 14 个顶面三角面，顶面实际有几何封口。
- 保留底部原装饰，补齐其隐藏背面的 8 个三角面，避免留下独立开边。
- 新增顶端表面复用原材质中主体的深色纹理区，避免采到灰色包边纹理。
- 原主体所有顶点未平移、旋转或缩放，坐标原点及插入参考位置不变。

## 遇到的问题

- Commandlet 内默认 StaticMeshEditorSubsystem 实例不可用，部分属性不可读。
- 网格的 UE 原三角面绕序与右手坐标下的有向体积符号相反。
- 原上沿 UV 向外延伸会采到材质图集中的灰色区域。
- 首次保存被 Windows 文件共享锁拒绝，错误 32；当前 Editor 仍打开目标资产。

## 处理方式

- 只用子系统 CDO 的无状态读取方法取得构建参数，不操纵当前 Editor 会话。
- 保留原绕序，用反向叉积构造新增面的外法线，并检查边朝向一致。
- 仅调整新增面的 UV，复用主体深色区域；原主体 UV 不变。
- 所有几何和设置检查在保存前完成，保存只指定目标 StaticMesh。
- 保存失败后核对 SHA256，磁盘目标仍与备份完全一致，没有残留半写入资产。
- 用户保存工作并关闭 Editor 后，确认进程自行退出且原文件哈希未变，再保存成功。
- 未强制关闭应用或改动文件锁。最终资产 SHA256：
  `443f77098f03f9f04789bcabf369670d19c18ac57e59794781d2353cf20bab83`。
