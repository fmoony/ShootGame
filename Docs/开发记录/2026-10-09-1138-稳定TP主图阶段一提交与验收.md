## 遇到的问题

- 首轮迁移 Getter 成员上下文错误，蓝图编译失败，失败轮没有保存资产。
- 首次 PIE 超过正式三 Slot 容量；后续随机出生点受阻导致 phase 2 超时。
- 资源检查遇到 Python 受保护数组、BlendSample 属性和曲线大小写问题。
- 验收发现资源在角色应用和完成事件中重复写入。
- 装备夹具有无骨骼 Socket、缺少 EndPlay、销毁时无 World Context 警告。
- PIE 有 GameplayCue 全 Game 搜索、清理阶段无 RecastNavMesh 和 ASC 无 Owner 警告。
- 原记录将 PIE 警告称为既存；证据只证明本轮前后存在，不证明阶段一之前已存在。
