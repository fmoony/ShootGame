# 实验原生动画图替代手工骨骼处理

- 日期：2026-11-15
- 计划提交说明：`重构：Stance 实验改为原生 AnimBP 并复核八向与 idle`
- 变更类型：实验代码 / 资产 / 工具 / 文档

## 目的

按用户要求完全取消 Stance 实验自写 C++ 动画处理。
在标准 SkeletalMesh 和原生动画图上重新检查八向穿地及下蹲 idle。

## 本提交完成内容

- 实验 Body、FP 改为 SkeletalMeshComponent，移除 PoseableMesh。
- 删除手工取样、FK、混合、分层、脊柱处理、握持 IK、骨骼回写及旧制作函数。
- 不保留 LegacyLower 等旧 C++ 姿态路径回退。
- 新增原生 TP／FP AnimBP，父类均为 Engine.AnimInstance。
- TP 使用原生序列、BlendSpace、姿态选择、缓存、AO 和分层；FP 用 Copy Pose。
- 生产自定义 AimIK 和左手 IK 未接入实验，正式生产节点和代码保留。
- C++ 只保留输入、固定 Actor 移动、相机、只读采集和离线资产建图。
- 增加公开 API 的图节点审计、实际骨骼导出及 raw／layered 对照分析。
- 更新当前运行脚本与文档，保留全部既有来源和旧步态资源。

## 遇到的问题

首次编译使用了不匹配的 GetAllGraphs 入口和私有组件字段。
首次建图用 MakeLinkTo，没有触发 Cast 输入类型推断，图编译失败。
Python 读取 ParentClass、Nodes 时受保护属性限制。
CodeGraph 命令不可用，按限定范围读取项目及本地引擎接口。
原始来源动画的接触混合和 idle 姿态类型问题仍在。

## 处理方式

改用 Blueprint.GetAllGraphs 及组件公开 setter。
改用 Schema.TryCreateConnection，失败图未保存，新图完整通过后才保存。
使用 BlueprintEditorLibrary 和 BlueprintGraphEditor 公开查询接口。
生产分层与 FP Copy Pose 配置先由官方 MCP 审计，再查询官方资料和本地签名。
两次真实原生运行独立核对，区分姿态链路正确与资源接触质量。

## 遗留项

正前、右后、左后缺少合适独立来源，混合接触及脚相位仍需资源制作。
需在 Blender 中制作或选择真正匹配半蹲移动的 idle，原跪姿来源继续保留。
未验收鞋底平贴、移动脚滑、精确握持、精确瞄准或生产完整 IK。
固定场景速度未做步幅匹配，滑铲仅播放旧序列，没有复刻旧位移控制。
网络、碰撞、坡面、台阶、换弹、贴墙、Cook 和滑铲整套回归未执行。
