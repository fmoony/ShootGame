# 武器弹药权威收敛到 WeaponActor

- 日期：2026-09-11
- 计划提交说明：`武器：将弹药与行为权威收敛到预配置 WeaponActor`
- 变更类型：生产代码 / 测试 / 构建

## 目的

按《武器启动预配置与实体池简化重构方案》S2 阶段要求，把 Magazine/Reserve 弹药权威
从 Inventory FastArray 迁入 WeaponActor 本体；FireBehavior 改为只读 Actor 冻结的
配置快照；玩家与 NPC 开火统一使用 Actor 弹药。Inventory 保留 InstanceId 外观 API
（转发实现），供 S3 统一删除。

## 本提交完成内容

- `AShooterWeapon`：
  - 删除 `CurrentBullets` 兼容镜像与 `OnRep_CurrentBullets`；新增权威字段
    `MagazineAmmo / ReserveAmmo`（COND_OwnerOnly + OnRep 推 HUD）。
  - 新增 `RestoreInitialAmmo`（绑定/应用行配置/归还池时恢复初始弹药经济）、
    `ReloadFromReserve`（Reserve→Magazine 原子换弹事务）、`PushAmmoToOwnerHud`
    （服务器扣弹/换弹与 Owner OnRep 共用推送，隐藏中不推）。
  - `ConsumeAmmo` 支持一次扣 N 发并推送 HUD；`CanConsumeAmmo / GetBulletCount /
    GetReserveAmmo` 不再回查 Inventory。
  - 新增 `ConfigSnapshot`（ApplyWeaponRow 冻结完整行配置）；`ExecuteFireAtTarget`
    的 FireContext.Config 只读该快照，不再查表。NPC 兼容路径弹匣打空自动回满
    改用 `MagazineAmmo`，行为与旧版一致。
- `ShooterInventoryTypes.h`：删除 FastArray 的 `ConsumeMagazineAmmo / ReloadMagazine`
  写事务与 `OnInstanceChanged` 桥；InstanceData 弹药字段保留为授予时只读快照（S3 删）。

  WeaponActor；移除 HandleInstanceChanged 镜像刷新路径。
- `GA_Reload`：激活校验与日志改读 WeaponActor 弹药（满弹匣/零备弹拒绝语义不变）。
- `AShooterCharacter`：装备表现收敛的 HUD 补推不再依赖 BoundInstanceId 到达。
- 测试改写：`ShooterInventoryReloadAutomationTests` 全量重写为 Actor 事务版
  （新增 `AShooterInventoryReloadTestWeapon` 测试武器）；`AmmoConsume`、GA_Reload
  数据契约改 Actor 路径；武器资产快检反射断言改为 MagazineAmmo/ReserveAmmo。
- `Scripts/Tests/BuildEditor.ps1`：显式 `-NoUBA`（原因见下），并按项目含中文脚本
  惯例补 UTF-8 BOM。

## 遇到的问题

1. **UBA 构建器稳定误报 C4756（常量算法中溢出，无源码位置）**：
   标准脚本（unity + UBA）稳定复现 ×2；同一 unity 文件、同一 rsp、vcvars 同环境下
   手工 cl 编译通过（EXIT=0）；`-NoUBA` 与 `-DisableUnity` 全量构建均通过；
   `Build.bat -Clean` 全清重建后 UBA 仍复现——排除源码错误与缓存陈旧，定性为本机
   UBA 执行器（Detours 拦截 cl）与当前 ShootGame 测试模块某 unity 编译单元的
   工具链兼容性问题。排查中曾误删 obj 后被 UBA 重放同一错误、并一度以为是陈旧
   rsp（实际 rsp 内容未变属正常）。
2. **BuildEditor.ps1 加中文注释后 PowerShell 解析失败**：中文注释以 UTF-8 无 BOM
   写入，Windows PowerShell 5.1 按本地 GBK 解析导致语法损坏；项目惯例为含中文
   脚本带 BOM（参照 RunFirstPersonCapture.ps1）。
3. **首轮全量 Automation 两例失败**：
   a) HUD 刷新测试：`PushAmmoToOwnerHud` 初版加了 `IsLocallyControlled` 前置，
      测试世界角色无 Controller 被跳过；弹药为 COND_OwnerOnly，OnRep 只在拥有端
      触发，该检查多余且改变了旧服务器推送语义。
   b) ReloadCapacity 测试：旧 `ConsumeMagazineAmmo` 支持一次扣 N 发（测试用 2），
      初版转发实现硬拒 `Amount != 1`。

## 处理方式

1. 在 `BuildEditor.ps1` 显式加 `-NoUBA` 并附注释指向本记录；UBT 本地执行器与
   手工 cl 均验证同一代码可编译，工具链更新后可移除该参数复验。期间遵守 UE
   项目规范：只用 UBT 自身机制（-Clean / -NoUBA / -DisableUnity）排查，未删
   Binaries/Intermediate 整目录，未触碰用户打开的 UnrealEditor 进程。
2. 脚本补 UTF-8 BOM 后解析恢复。
3. a) 移除 `IsLocallyControlled` 前置，恢复"装备可见即推送"旧语义；
   b) `ConsumeAmmo` 增加 Amount 参数（默认 1，弹匣不足整体拒绝），转发透传。

## 遗留项

- `-NoUBA` 为环境级规避：后续 VS/UBA 工具链更新后应移除并复验（建议在 S5 回归
  前试一次）。
- InstanceData 弹药字段与 Inventory InstanceId 转发 API 为迁移期外观，S3 删除。
- NPC 仍走直接 Spawn 兼容路径（弹匣自动回满），S4 迁入同一 WeaponId 池。
