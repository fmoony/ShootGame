# 统一文本行尾并增加门禁

- 日期：2026-09-13
- 计划提交说明：`规范：统一文本行尾并增加门禁`
- 变更类型：测试 / 文档

## 目的

落实 `.editorconfig` 已规定的 CRLF 行尾，修复上一提交编辑后产生的纯 LF 与混合行尾，
并防止相同问题再次通过增量版式门禁。

## 本提交完成内容

- 将上一提交涉及的文本工作副本统一为 CRLF，并确保文件以 CRLF 结束；
- 在代码规范中明确 CRLF、文件末尾换行及禁止混合行尾的要求；
- 为 `CheckTextLayout.ps1` 增加文件级行尾检查，对纯 LF、孤立 CR、混合行尾及缺失末尾换行报错。

## 验证结果

- PowerShell Parser：`CheckTextLayout.ps1` 语法通过；
- 定向行尾验证：统一后的 `ShootGame.Build.cs` 判定 Pass，纯 LF 对照文件判定 Fail；
- 工作副本字节检查：本次 6 个相关文本均只有 CRLF，裸 LF 与孤立 CR 均为 0，
  且文件末尾均为 CRLF；
- `CheckTextLayout.ps1 -Scope Staged`：Passed，检查 3 个文件，0 警告；
- `git diff --check` 与 `git diff --cached --check`：Passed；
- 未运行编译与完整回归：本提交只修正文本行尾并补充静态门禁，不改变构建或 Gameplay 行为。

## 遇到的问题

- `.editorconfig` 已声明 `end_of_line = crlf`，但原版式检查器只检查显示宽度、缩进与折行；
- 补丁编辑后的多个文件分别呈现纯 LF 或 CRLF/LF 混合状态。

## 处理方式

- 继续以 `.editorconfig` 为行尾权威，并在现有增量门禁内补充字节级校验。

- 无。
