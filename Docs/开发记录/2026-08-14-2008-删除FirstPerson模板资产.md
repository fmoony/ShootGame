## 目的

4 个仍被 Shooter 使用的资产已经迁移，旧 FirstPerson 路径也已没有目录外引用。本提交删除剩余示例地图、模板 GameMode/PlayerController、材质 Redirector 及地图 External Actor/Object，完成 FirstPerson 内容目录清理。

本提交不清理 `DefaultInput.ini`、`DefaultEditor.ini`、`DefaultEditorPerProjectUserSettings.ini` 或历史 Class Redirect，也不修改根目录 C++ 类。

  - `BP_FirstPersonGameMode`

  - `Lvl_FirstPerson`

- 更新 `Docs/FirstPerson清理与架构审计.md`，标记三个 FirstPerson 资产目录已经移除。

## 遇到的问题

- UE 脚本先删除主地图后，剩余 External Actor 的 Level Outer 已不存在，`EditorAssetLibrary.delete_directory` 无法加载并删除 `/Game/__ExternalActors__/FirstPerson`，只自动删除了其中 1 个 Actor 和唯一的 External Object。
- Headless Commandlet 同时报告受限环境中的 Derived Data Cache 无可写节点；该环境错误与删除目标无关。

## 处理方式

- 删除前已经通过 Asset Registry 证明全部 70 个包没有目录外引用，并把删除目标限制在三个明确的 FirstPerson 目录。
- 对 UE 无法加载的 64 个孤立 External Actor 文件，先解析并确认绝对目录位于项目 `Content/__ExternalActors__/FirstPerson` 下，再以文件系统方式删除该精确目录；没有使用通配符或上级目录。
- 上一提交 `1a21525` 保留了删除前完整状态，可恢复本次全部资产。

## 遗留项

- 配置文件中仍有 FirstPerson 触控界面、编辑器默认浏览路径、旧示例地图和历史 Class Redirect 文本；按用户要求本步完成后停止，留待后续独立提交。
- `AShootGameCharacter` 仍是 Shooter 玩家与 NPC 的共享基类，其中早期 NetCounter/RPC 实验代码尚未清理。
- 根目录 `AShootGamePlayerController`、`AShootGameCameraManager`、`AShootGameGameMode` 和 `AShootGameGameState` 尚未处理。
