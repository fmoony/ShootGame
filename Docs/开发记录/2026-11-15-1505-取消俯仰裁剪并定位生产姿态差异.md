# 取消俯仰裁剪并定位生产姿态差异

- 日期：2026-11-15
- 计划提交说明：动画：取消实验俯仰裁剪并量化生产瞄准姿态差异
- 变更类型：Editor 测试 / 脚本 / 文档

## 目的

取消 Stance 上下俯仰额外限制，查明实验为何不能复现生产的轻微脊柱后仰与手臂旋转。

## 本提交完成内容

- 移除实验正负 85° 与 -45° / +55° 两层 Pitch 裁剪，保留控制器和引擎常规视角语义。
- 108 场景新增正负 90° 覆盖，完整采样五节脊柱、颈部及双臂，共 17 骨。
- 扩展 analyze_view.py 兼容完整骨骼采样，继续验证分层与 FP 复制。
- 新增 analyze_pitch.py，计算实际脊柱响应及关节局部旋转变化。
- 新增只读 export_production_pitch.py，求值实际生产 AO 的压缩端点完整姿态。
- 读取 Rifle 配置和正式节点，不修改生产代码、蓝图、动画或 Blender 文件。
- 更新当前说明，新证据独立归档，历史开发记录和验证目录保留原貌。

## 验证结果

- Editor 构建成功，使用 UsePrecompiled、NoEngineChanges 与 NoUBA。
- 108 场景、2,160 个采样帧，实际脊柱响应达到正负 90°，角度误差小于 0.000004°。
- FP 与 Body 位置差为 0，完整上身与站立参考位置差约 0.000001 cm。
- 实验向上 90° 时，上胸累计 90°，右上臂和右手局部旋转变化为 0°。
- 生产 AO 向上端点：上胸组件旋转约 17.31°、右上臂局部约 51.20°、右手局部约 25.41°。
- 生产数据是原生资源求值，未宣称完整生产 AnimBP 已运行。
- 保护资产哈希、语法、include、版式及 diff 检查通过；真实暂存区未修改，未提交。
- 仅修改已有 C++ 文件，新增 Python 脚本不要求刷新 VS 工程。

## 遇到的问题

- CodeGraph 命令不可用，按约定限定读取生产动画代码。
- 单看组件总旋转会将父级带动误认为手臂独立旋转。
- 原九骨采样缺少脊柱、颈部和前臂父级，无法完整计算关节局部变化。
- 放宽脊柱角度本身不能生成生产 AO 中的肩臂动作。
- 引擎仍有既存 StateTree 弃用、IncludeOrder 和辅助 SDK 提示。

## 处理方式

- 查询实际 Rifle 数据表及 AO 样本，并对照 Epic 文档和本地增量求值实现。
- 完整记录 17 骨，以父级逆旋转计算关节局部旋转，区分总旋转与独立关节动作。
- 用实际 Body 上胸的前后旋转验证解除裁剪，不用截图推断角度。
- 生产 AO 端点按声明的 Additive Base 还原为完整姿态，明确参考证据边界。
- 保留纯脊柱实验实现作为当前状态，没有擅自将生产姿态资源改写成固定权重。
- 骨骼列表按多行数组规范整理后完成最终构建复核。

## 遗留项

- 当前仍为五节脊柱分摊全部 Pitch，右臂缺少独立 AO 轨道。
- 要复现轻微后仰与抬臂，需要接入实际 AimOffset 及后续 AimIK，尚未实施。
- 现有约 14.42° 枪口基准差、脚掌平贴及启停穿地仍未解决。
- 未做正式网络、换弹、贴墙、Cook 和完整滑铲回归。
