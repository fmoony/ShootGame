# 完成 AnimBP 数据契约并删除反射 PitchN 写入

- 日期：2026-08-22
- 计划提交说明：`表现：AnimBP 数据契约完成并删除运行时反射 PitchN 写入`
- 变更类型：生产代码 / 测试 / 资产 / 文档

## 目的

完成《第三人称瞄准表现同步实施计划》§B3/B6 的 AnimBP 数据契约闭环：AnimBP 蓝图侧改为通过明确的 Character Getter 读取平滑后的表现俯仰（用户已在编辑器中完成 ABP_TP_Rifle / ABP_TP_Pistol 的接线改造），C++ 侧删除运行时反射写入路径，使“运行时不再通过字符串反射写入 AnimBP PitchN”的完成定义成立。

## 本提交完成内容

### 资产（用户编辑器操作）

- `ABP_TP_Rifle.uasset` / `ABP_TP_Pistol.uasset`：AnimGraph 中 AimOffset（RotationOffsetBlendSpace）的 Y 输入来源由 `PitchN` 变量节点改为 `Get Owner → Cast To AShooterCharacter → GetAimPitchN`（Character Getter 数据契约）。AO 拓扑与分层结构不变。

### 生产代码（`Characters/ShooterCharacter.h/.cpp`）

- 新增 `GetAimPitchN()`（BlueprintCallable）：返回 sin(radians(局部 AimPitch))，值域 [-1, 1]，与旧 PitchN 契约（瞄准前向与世界 Up 点积）语义一致，AO Y 轴直接消费（AO 资产 Y 轴样本为 ±1 已核验）。
- **删除**：`ApplyRemoteAimPitch()`（含实现与声明）、`PostNetReceive()` 覆写（仅服务反射写入）、`OnRep_CurrentWeapon` 中的 `ApplyRemoteAimPitch()` 调用、`FindFProperty<FNumericProperty>(..., TEXT("PitchN"))` 运行时写入。

### 测试代码

- `ShooterWeaponAutomationTests.cpp`：`ShootGame.Weapon.Configuration` 的“AnimBP 暴露 PitchN”断言改为验证数据契约（`AShooterCharacter` 暴露 BlueprintCallable `GetAimPitchN`）。
- `ShooterNetworkTestCoordinator.cpp`：远端瞄准观察从读取 AnimInstance `PitchN` 反射属性改为调用 `RemoteCharacter->GetAimPitchN()`（观察端平滑收敛后与 `GetBaseAimRotation().Vector().Z` 一致，容差 0.05）。
