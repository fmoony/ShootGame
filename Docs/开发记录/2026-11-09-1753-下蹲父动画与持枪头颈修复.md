# 下蹲父动画与持枪头颈修复

- 日期：2026-11-09
- 计划提交说明：`动画：补齐下蹲父动画并修正持枪头颈`
- 变更类型：隔离动画 / Editor 夹具 / 脚本 / 文档

## 目的

修复原隔离地图按 2 后的 idle 右脚悬空及持枪低头。
本轮只聚焦画面，不重跑全量 Gameplay、网络或迁移验收。

## 本提交完成内容

- 从五份原始 FBX 提取骨架外父节点动画，源文件和导入资产保持。
- 按已验证的 Y-up、XYZ 与厘米格式处理；不支持的格式明确拒绝。
- 去掉初始平面摆放及朝向，将父动画先恢复到骨盆，再镜像与组合持枪层。
- 移动素材另去掉水平净行进，保留周期摆动，避免与实验 Pawn 位移重复。
- 保留原肩臂 Aim / LowReady 覆盖、握持校正与运行时脊柱瞄准。
- 将初始持枪头部方向差分摊到两段颈骨，保留逐帧变化和躯干前倾。
- 不改变头骨局部轨道，不将颈链修正扩展为正式角色的新系统。
- LowReady 单独降低武器，头部使用独立 Aim 视线基准。
- 验证基准改为原 FBX 父动画，并分别检查 idle 左右脚支撑点。
- 增加 CaptureIdle：六个完整 idle 视角场景及四个 ±25° 俯仰场景。
- 只使用原地图，不创建新场景，不改正式 AnimBP 或角色。

## 实现依据

继承[父变换分析](2026-11-09-1735-下蹲接地低头与分层分析.md)的来源对照。
原 FBX 动画父节点与 UE 导入骨架的差异已逐帧定位，不依赖猜测导入选项。
本轮沿用现有离线烘焙职责，未新增运行时网络或生产动画架构。
恢复完整底姿后，肩臂仍单独持枪；颈链承担持枪初始朝向差，而非抬整个躯干。

## 验证结果

- 五份父动画与原 FBX 全局脚尖高度差的最大误差小于 0.00006 cm。
- Editor 最终增量编译通过：107.81 秒，13 个项目动作。
- MSVC 14.50.35739、SDK 10.0.26100.0，单并发、UsePrecompiled 与 NoEngineChanges。
- 独立资产读回通过，22 段动作，最大位置误差 0.04235 cm、旋转误差约 0.03476°。
- LowReady 视线基准修正后增量编译通过：110.01 秒，13 个项目动作。
- 最终原地图 D3D12 / SM6：10 场景、1510 帧、10 张全新截图，全部断言通过。
- 六个完整 idle 场景覆盖 Aim / LowReady 与三个外部视角，另四个检查 ±25° 俯仰。
- 左右脚尖骨支撑点约 0～0.3932 cm；视线最大偏离约 3.02°，左手握持检查通过。
- 已逐张查看全部 10 张最终截图，确认右脚支撑及 Aim / LowReady 头部方向改善。
- 完整来源仍为单膝姿，后侧脚跟抬起、脚趾支撑；不是强行制作双脚掌平贴。
- 此前不能凭双脚尖同高推断为双脚掌蹲姿；新截图据实澄清，历史材料不改写。
- 原工程 58 个未提交文件、18 个引擎基准及本轮 20 个保护文件均保持哈希。
- 项目与引擎 Build ID 同为 db931d31-8703-4c38-b2b7-93dc445fd12b。
- 本轮没有运行完整 Gameplay 自动化、网络、Cook 或 Stage。
- 版式与 Include 门禁通过；末尾仅合并一处 C++ 冗余换行，语句未变，不重复编译。

## 遇到的问题

- CodeGraph 不可用，限定读取既有 Stance 夹具及分析材料。
- 初次编译因 FString::Printf 的动态格式串不满足编译期检查而失败。
- 移动来源父节点还包含水平净行进；仅去掉初始位置会让原地循环产生跳跃。
- 本轮辅助编辑脚本出现过 UTF-8 读取和 PowerShell 表达式问题，未改写来源资源。
- 首次新模块启动耗时较长，实际烘焙前需等待引擎模块装载。
- 独立验证器重算颈链时遗漏接地平移；修正计算后原精度门禁通过。
- 首轮 LowReady 仍有约 28.8° 视线偏离，来自收枪来源自带的头部角度。

## 处理方式

- 改用静态格式串，保留已有编译缓存后完成项目增量构建。
- 分离摆放、净行进和姿态，保留旋转及循环细节。
- 只读交叉验证所有来源，头颈和接地通过实际生成结果再次检查。
- 专用采集拒绝旧截图；不扩大超时、不跳过头部或左右脚断言。
- 保留首轮 10 张截图、完整 CSV 与失败摘要；将头部基准与收枪层分离后再采集。
- 只维护一份工作区进度文档，结束时汇总后删除。
