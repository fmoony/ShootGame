# 编码与文档换行规范

- 日期：2026-09-12
- 计划提交说明：`规范：增加代码与文档换行标准及增量检查`
- 变更类型：规范 / 开发脚本

## 目的

补齐项目缺失的行宽、续行和 Markdown 排版规则，减少人工编码产生的随机折行，
并建立只约束新增或修改行的增量门禁，避免一次性重排历史代码。

## 本提交完成内容

- 新增 `.editorconfig`，统一 UTF-8、CRLF、行尾、Tab 与可视行宽提示；
- 新增 `.clang-format`，定义 UE 风格的 120 列 C++ 自动排版基线；
- 新增 `Scripts/Development/CheckTextLayout.ps1`，支持检查暂存区、工作区或全仓文本；
- 检查器保留 C++ 块注释惯用的单空格 ` *` 前缀，不将其误判为代码缩进；
- 更新 `Docs/代码规范.md`，明确代码与 Markdown 的换行规则、例外和提交门禁；
- 更新 `AGENTS.md`，要求每个新提交检查暂存区新增或修改行。

## 验证结果

- PowerShell Parser：`CheckTextLayout.ps1` 语法通过；
- `CheckTextLayout.ps1 -Scope Staged`：Passed，检查 4 个受支持文本文件；
- `git diff --cached --check`：Passed；
- 本提交不修改生产代码、配置或资产，不运行 Unreal 编译与七阶段回归。

## 遇到的问题

- 当前机器未发现可直接调用的 `clang-format.exe`；
- 历史源码和文档已有较多超长行，不能立即对全仓启用硬失败。

## 处理方式

- `.clang-format` 只使用兼容性稳定的基础选项；当前提交先由增量检查脚本提供强制门禁；
- 检查器默认只检查暂存区新增或修改行，历史问题由独立格式提交逐步收敛。

## 遗留项

- 固定 `clang-format` 命令行版本后，可增加自动格式化入口；在此之前不依赖未验证的本机工具路径。
