# 提供可移植的 UE 5.8.4 开发入口

- 日期：2026-11-06
- 计划提交说明：`工具：提供可移植的 UE 5.8.4 开发入口`
- 变更类型：构建 / 文档

## 目的

让 Windows 开发者按各自安装位置使用同一 UE 5.8.4 工程。

## 本提交完成内容

- 增加引擎位置解析、可选用户级关联注册和项目启动入口。
- 更新现有构建、网络与辅助测试脚本的默认引擎解析。
- 使用 Lvl_Shooter 作为网络脚本默认地图，补充 Windows 开发说明和本地输出排除。

## 验证结果

显式路径和用户级 GUID 均已解析至本机已验收的 5.8.4。
项目文件生成通过，新 worktree 已成功编译编辑器。

## 遇到的问题

旧脚本默认使用固定的 5.6 安装目录，无法在其他开发机上直接复用。

## 处理方式

统一使用显式参数、环境变量或用户注册表查找，并校验版本。

## 遗留项

其他开发机需要提供自己的引擎目录，或一次性注册关联。
