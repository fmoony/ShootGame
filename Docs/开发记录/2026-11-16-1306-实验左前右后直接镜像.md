# 实验左前与右后直接镜像替换

- 日期：2026-11-16
- 计划提交说明：资源：以直接镜像替换实验左前与右后
- 变更类型：动画资产 / Blender 源文件 / 工具 / 验证 / 文档

## 目的

按用户要求用右前镜像制作左前、用左后镜像制作右后。
不增加之前的独立肢体求解、接地或轨迹修正。

## 本提交完成内容

- 制作两段直接镜像，保留 60 FPS、61 点和原时间轴。
- 正确交换左右骨骼及脚部标记，按生产参考轴处理旋转反射。
- 保存新的 Mirrored blend、FBX、逐帧目标与镜像保真报告。
- 通过标准 FBX 绑定生产 Skeleton，仅替换 BS 的左前、右后引用。
- 八向单点布局、来源、其余样本、AnimBP 与 C++ 均保留。
- 更新当前验证入口与现状，历史报告未修改。

## 验证结果

308 个保护文件、镜像双重回转、原始/压缩导入、循环与原生图检查通过。
32 方向实际采 5,680 帧，FP 复制世界位置差为零。
左前、右后两持枪主方向均为 0/68 帧双脚表面相交。
鞋面穿地约 4～5 cm 仍从来源继承；相邻混合接触检查为 Failed，
其中右后到后退一侧的前掌最低约 -13.7 cm，未隐去失败结果。
脚步高度没有调整，时间相位没有改变。
文本版式与 diff 检查通过，工作区未提交。

## 遇到的问题

直接镜像消除了本次主方向采样中的双脚相交，却不会消除来源的鞋面穿地。
与原轴向混合还出现骨骼点穿地，不能把镜像验证通过解释为所有接触问题修复。

## 处理方式

分别保存镜像保真和接触质量结论。
按用户“不要多余解算”的约束保留直接镜像，不追加 IK、优化或移相。
只读相位对照没有消除全部问题，也没有写入制作资源。

## 遗留项

鞋底表面穿地、相邻方向混合兼容、脚滑与自然度待后续处理。
原 idle 仍为单膝跪姿，坡面、网络和完整生产接入未验收。
已恢复可视化 UE 5.8 实验 PIE。
