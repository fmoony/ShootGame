## 遇到的问题

- 前一轮 Landing 观察脚本用 0 / 1 猜测 GetCurrentStateName 的节点索引，
  导致 EXCEPTION_ACCESS_VIOLATION；该索引不是状态机数组序号。
- 本轮临时观察对象 AddToRoot 保活后没有在结束 PIE 前解除 Root，
  三次初始会话在 EndPlayMap / UWorld::MarkObjectsPendingKill 阶段触发
  Assertion failed: !IsRooted()。动画过程结果不等于完整退出验证通过。
- 临时工具编译曾使用不存在的 Entry.GetOutputPin 和受保护的 GetMachineDescription。
  首次异步 PIE 脚本还因 ExecutePythonScript 默认行为，在脚本返回后提前正常退出。

## 处理方式

- 状态观察改用 GetStateMachineInstanceFromName，不猜测编译节点索引，
  并确认实例已执行首次 Update 后才读取状态。
- 结束 PIE 前先解除 OnAnimInitialized 绑定，清空 Mesh 引用，RemoveFromRoot，
  清空观察列表，再请求 EndPlay；重新执行两组回归并确认正常退出。
  崩溃来自 Agent 临时工具清理错误，没有扩大 Gameplay 或动画修复范围。
- 核对本地 UE5.6 API 后使用 Entry 的实际引脚和公开初始化检查。
  异步 PIE 明确保持 Python 脚本存活，结束后恢复设置并退出。
- 三个 ShootGame 崩溃报告窗口均正常关闭，最终检查无报错进程残留。
  没有强制结束其他项目进程，也未提交崩溃报告。
- 最终删除辅助源码，按规范只刷新一次 VS 工程，重新构建并重载资产。
