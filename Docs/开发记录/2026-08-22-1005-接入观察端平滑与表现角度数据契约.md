# 接入观察端平滑与表现角度数据契约

- 日期：2026-08-22
- 计划提交说明：`表现：观察端平滑表现目标并建立 AimYaw/AimPitch 数据契约出口`
- 变更类型：生产代码 / 测试

## 目的

执行《第三人称瞄准表现同步实施计划》B3/B4 的 C++ 侧：观察端把复制到的 `PresentationAimTarget` 平滑为可消费的表现目标，并输出局部 AimYaw / AimPitch 数据契约；B4 首选路线复用现状（`bUseControllerRotationYaw=True`，身体已跟随控制器水平朝向），本提交不重复创建身体旋转系统。AnimBP 蓝图侧的契约接线（AO 输入改接 Character Getter）需要编辑器操作，作为用户事项在本提交之后进行（见遗留项）。

## 本提交完成内容

### 生产代码（`Characters/ShooterCharacter.h/.cpp`）

- 观察端平滑（仅 `ROLE_SimulatedProxy`，Tick 内运行）：
  - `SmoothedPresentationAimTarget`（本地成员，不复制）：每帧向最新网络目标指数插值（`PresentationAimSmoothingRate=8/s`，B3 调试起点）。
  - 回退：超过 `PresentationAimFallbackDelay=0.5s` 没有新网络目标时，回退到 `GetBaseAimRotation()` 方向（角色 Forward + 当前远端 Pitch）× MaxAimDistance，不保持任意历史点。
  - 重置（直接采用最新目标，不从旧值插值）：首次初始化、武器切换（`OnRep_CurrentWeapon`）、死亡（`ApplyDeathState`）、传送/重生（视点跳变 >500cm/帧检测）。
- 局部角度契约出口（计划 §B3 公式）：
  - `GetAimPresentationAngles(float& OutAimYaw, float& OutAimPitch)`（BlueprintCallable）：世界方向 = 平滑目标 − Pawn 视点（AimPivot），局部方向 = Mesh 变换逆变换，AimYaw / AimPitch 由 `FShooterAimMath::WorldDirectionToLocalAngles` 计算（±180 环绕已由该函数处理）；拥有者或回退时基于 `GetBaseAimRotation()`。
- B4：身体水平朝向继续由 `bUseControllerRotationYaw=True` 承担（B1 审计确认，未改动）；AimOffset X 保持 0（无左右样本），本提交只建立可测量的 AimYaw。

### 测试代码（`Tests/Network/ShooterNetworkTestCoordinator`）

- B1/B2 会话模式扩展 B3 观察端验证（`B3_AIM_SMOOTHING_OBSERVER`）：
  - 平滑目标存在且收敛到网络目标（最小间距 ≤ 50cm）。
  - 局部 AimPitch 与远端 GetBaseAimRotation 俯仰一致（差值 ≤ 20°，实测 ≤ 0.3°）。
  - 局部 AimYaw 稳定性（相对首个采样点漂移 ≤ 30°）：第三人称 Mesh 带固定相对偏航（实测 ~90°），绝对值是常数偏移，判据用稳定性而非绝对值有界。
