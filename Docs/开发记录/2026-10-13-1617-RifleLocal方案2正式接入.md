## 遇到的问题

- 直接把 Editor/Test 原型父类接入正式图，会留下运行期测试依赖，不能作为正式实现。
- 初次严格对照差 0.015 cm / 0.128°，ArmedAim 首帧已有差异，两套 Hold 更新相位不一致。
- 临时副本重设父类后立即创建 Hold 变量引脚，出现空引脚并导致比较进程异常退出。

## 处理方式

- 仅迁移必要的 Runtime 节点；保留正式父类、原播放器、状态机和所有 Gameplay 路径。
- 在不保存的比较副本中加入与原型相同的 Hold 测试输入，统一相位后严格复测通过。
- 先编译临时父类结构，再重建引脚，并在连线前检查两个引脚；正式资产未受比较失败影响。
- 原差异 CSV、失败日志及最终通过日志均保留；不把初次失败改写为成功。
- Blueprint API 无创建动画节点能力，先通过 MCP 读图，再由限定目标的原生工具接入。
- 官方节点职责对照：[Animation Node Technical Guide](https://dev.epicgames.com/documentation/unreal-engine/animation-node-technical-guide-in-unreal-engine?application_version=5.6)。
- 本地 UE5.6 LBB 更新代码仅在权重相关时推进子 Pose，支持保留原型的更新权重分离。
