# Rifle 左手 IK 与瞄准表现基线

- 日期：2026-08-25
- 计划提交说明：`动画：提交 Rifle 左手 IK 与瞄准表现基线`
- 变更类型：生产代码 / 测试 / 文档 / 资产

## 目的

建立 Rifle 第三人称双手握持闭环，修复近墙目标造成的第三人称武器剧烈抖动，并让远端角色消费拥有者提交的表现瞄准目标。在不改变服务器权威开火、命中和伤害逻辑的前提下，保存当前已经通过人工验收的 IK 与瞄准表现基线。

## 本提交完成内容

- 在 `AShooterCharacter` 中建立拥有者 20 Hz 表现目标采样、Unreliable Server RPC、序号与距离校验、`COND_SkipOwner` 属性复制及观察端平滑状态；权威开火仍现场计算目标，不消费表现快照。
- 将远端第三人称 AimDirection 改为从第三人称枪口指向平滑表现目标，并为近点或枪口后方目标建立连续安全投影，消除贴墙时的方向奇异和持续抖动。
- 将观察端表现目标指数平滑速率由 `8/s` 提升为 `20/s`，保留现有 20 Hz 网络预算；大范围甩枪的进一步响应优化留到后续专用同步阶段。
- 新增 `FAnimNode_ShooterLeftHandIK` 与 `FShooterLeftHandIKMath`：使用武器握把和角色手掌完整参考帧计算 `hand_l` 目标，通过 Two Bone IK 求解上臂、前臂和手掌，并在快速横扫时保持肘部 Pole 位于同一半球。
- 将 Shooter Aim IK 默认最大右手校正从 30 度降低为 12 度，使 AimOffset 与基础上半身动画承担主体姿势，右手只处理小角度枪口残差，左手 IK 只负责握把闭环。
- 扩展 Aim 表现目标、角色消费边界、近点安全方向、左手握把参考帧、启用状态、缓存刷新和 Pole 稳定性的自动化测试，并修正联机协调器相关阶段门。
- 保存 `/Game/Shooter/Animation/ThirdPerson/ABP_TP_Rifle` 当前节点连接和参数结果；同时按全量提交要求纳入工作区已有的 `/Game/Shooter/Animation/FirstPerson/ABP_FP_Weapon` 资产修改。
- 更新《武器贴墙稳定与瞄准表现收尾实施计划》，记录阶段 0～4 的自动化和人工结果，以及大范围甩枪同步仍未收尾的边界。

## 遇到的问题

- 相机命中点接近或位于第三人称枪口侧后方时，`Muzzle → Target` 方向对微小目标变化过度敏感，导致武器和双臂持续抖动。
- 最初使用逐帧 Pole 投影、固定半球和 Pole 角速度限制，快速左右甩动时左肘仍会外翻或出现类似橡皮筋的跳变。
- 固定 `8/s` 观察端平滑与 30 度右手枪口校正叠加后，右手和武器承担过多角度变化，左手 IK 被迫追逐移动中的握把。
- 大范围快速甩枪时，远端动画响应速度仍低于预期。

## 处理方式

- 将近点表现目标沿基础视线连续投影到安全深度，保留横向视差，同时避免枪口后方奇异方向。
- 保留 Pole 同半球保护，但撤回人工视觉失败的 Pole 角速度限制，不继续用左肘平滑掩盖上游问题。
- 提高观察端平滑收敛速率，并把 Shooter Aim IK 最大右手校正降到 12 度，减少左手 IK 需要追逐的角度范围。
- 将大范围甩枪响应从 IK 问题中分离，后续优先评估自适应方向追赶；仍不足时再考虑压缩 AimYaw/AimPitch 与短时角速度外推。
