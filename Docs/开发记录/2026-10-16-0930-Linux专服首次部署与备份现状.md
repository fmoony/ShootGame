## 遇到的问题

- 首次构建入口仅 build UBT，缺少 publish，未能启动真正的 Server 编译。
- 原始源码 CL=0 与 Launcher 客户端不兼容，首次公网握手被拒绝。
- Linux 打包缺少两张 IOS 依赖图片；Windows UAT 缺少同版程序集。
- Windows Cook 曾遇到默认 Shader 临时目录的沙箱权限问题。
- 完整备份下载被用户暂停；取消时出现 Paramiko 预取线程关闭异常。
- 10 月 16 日连接未读到 SSH 协议 banner，未进入认证。
- 本地约 16 GiB 内存，E 盘约 179 GiB 可用，尚无交叉构建峰值测量。
- 用户此前全量源码编译超过 300 GB，不能承诺当前空间足够。

## 处理方式

- 使用官方 BuildUBT.sh 发布 UBT，再通过 RunUBT.sh 构建，保留原失败日志。
- 仅修正隔离源码副本的发布版本元数据，增量重编及打包，未绕过网络版本校验。
- 使用同版依赖与源码构建程序集补齐缺失项，未覆盖已有 DLL，回退清单保留在 Saved。
- 将 Shader 工作目录限定到本轮 Saved 目录，未更改 Gameplay。
- 暂停后按用户新指令删除 G 盘未完成备份，保留 D 盘运行包及项目内证据。
- 明确区分 SSH 握手失败和服务器关机；依用户要求停止继续连接检查。
- 本地交叉编译维持评估状态，先核算空间预算，不启动编译。
