- 变更类型：生产代码 / 测试

## 目的

执行《Shooter 核心玩法架构解耦重构执行计划》R6.1：建立 `UShooterAnimInstanceBase` 薄公共基类与 `UShooterFirstPersonAnimInstance` 第一人称适配层，并把 `UShooterThirdPersonAnimInstance` 改到公共基类下，让两套视角在数据采集上共享一个克制契约，同时不把视角专用数据上提。

## 本提交完成内容

- 新增 `Characters/Animation/ShooterAnimInstanceBase.h/.cpp`：
  - 缓存 Owning Character；
  - 每帧采集 GroundSpeed / bIsInAir / bHasEquippedWeapon / CurrentWeaponActor；
  - 从 ASC Tag 只读采集 Firing / Reloading / Equipping / Dead；
  - `NativeInitializeAnimation / NativeUninitializeAnimation / NativeUpdateAnimation` 公共骨架；
  - 子类钩子 `UpdateShooterAnimationData` 与 `ClearCommonAnimationData`。
- 新增 `Characters/Animation/ShooterFirstPersonAnimInstance.h/.cpp`：
  - 仅本地拥有者且 Mesh/当前武器有效时 `bFirstPersonDataValid=true`；
  - 无本地控制、无 Mesh、死亡、无武器时清空专用快照；
  - 不复制任何第一人称专用相机或手臂状态。
- `UShooterThirdPersonAnimInstance`：
  - 改为继承 `UShooterAnimInstanceBase`；
  - 原 `NativeUpdateAnimation` 改为 `UpdateShooterAnimationData` 钩子，公式与专用缓存逻辑不变。
- 新增 `Tests/Animation/ShooterAnimInstanceHierarchyAutomationTests.cpp`：锁定类型层次、公共字段、视角专用字段不上提、基类无 Net 函数。
- 运行一次 VS 项目刷新脚本。
