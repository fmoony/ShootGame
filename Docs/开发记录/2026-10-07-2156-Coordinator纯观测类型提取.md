# Coordinator 纯观测类型提取

- 日期：2026-10-07
- 计划提交说明：`重构：提取 Coordinator 纯网络观测类型`
- 变更类型：测试

## 目的

`Tests/Network/ShooterNetworkTestCoordinator.h` 原先有 1911 行，其中 399 行是
与 Actor 生命周期无关的纯数据 / 纯计算类型：不持有 Actor 生命周期、不注册委托、
不发 RPC、不访问 World、不推进 Stage，却要求任何关心这些数据形状的代码都包含
整个测试 Actor 定义。

本次只调整「数据形状的归属」：把这些类型提取到轻量数据头，让 Coordinator 头
专注 RPC / Stage / Timer / 复制状态 / 身份解析，并让纯统计消费者可以直接依赖数据头。

不拆 Actor、不移动任何流程控制、不修改生产代码与 Gameplay。

## 遇到的问题

1. 定义块定位脚本首版按「多行 doc」匹配，而
   `FShooterReloadIdentityObservation` 的 doc 是单行注释，断言失败并中止
   （未修改任何文件）。
2. 新文件由 write / here-string 产出时是 LF 行尾（其中 21 行 LF-only），
   与项目 CRLF 约定不符。
3. 编辑过程中两次 `edit` 报 `ReplaceFileW EIO (Win32 1175)`（文件被外部进程占用）。
4. 联机会话前两次失败：第一次用 `-ClientCount 1`（历史 106 次 AmmoPrediction
   运行中只有 2 次用 1 客户端）；第二次改成 2 客户端，但**只给服务器传了
   `-ShootGameAmmoPredictionTest`**，客户端因此没有进入夹具模式 ——
   客户端 `AMMO_PREDICTION_*` 标记 0 条、跑的是普通 `Stage=Inventory.Owner`
   流程，服务器等不到样本而超时。
5. 工作区同时存在另一主题的未提交改动
   （`Inventory/ShooterInventoryTypes.*` 的列表操作实现下移），
   本轮验证与它共用同一次 Build 与 Automation。

## 处理方式

1. 定位规则改为「doc 起始行 + 前瞻一行」并加内容断言（块跨度、块后空行、
   后继内容），断言通过后才执行删除。
2. 新文件与拼接结果统一归一化为 CRLF 后复核（LF-only=0、无 BOM）。
3. EIO 后直接重试，两次均成功；未做任何绕行改写。
4. 对照历史绿色会话的命令行，确认该夹具要求**服务器与客户端都带**测试 flag；
   修正后同一二进制一次通过 12/12 与 4/4。归因依据不止「改了就过」：
   失败时客户端标记为 0 且运行的是普通流程，而承载样本的 RPC 实现与本改动无关。
5. 该 Inventory 改动未被触碰，拆成独立提交（见
   `Docs/开发记录/2026-10-07-2153-Inventory列表操作实现下移.md`）。

## 遗留项

- 建议**不再继续拆 Coordinator**：剩余可议项中，
  `FShooterFireSpecGrantForTest` / `FShooterFireActivationContextForTest` /
  `FShooterFireContextAggregateForTest` 是 Actor 的嵌套公共类型，外移等于给所有

  `const UShooterGameplayAbility_Fire*`）；`FAimTurnCsvPreviousSample` /
  `FAimTurnCsvPoseProbe` 是 CSV 诊断探针状态（后者带 `FDelegateHandle` 与
  注册 / 注销语义），不是纯观测；其余约 1470 行是 RPC / Stage / Timer /
  复制字段 / 身份解析，按任务边界本就不应移动。
- `ShooterNetworkTestCoordinator.h` 仍包含 `Weapons/ShooterWeapon.h`、
  `AI/ShooterNPC.h`、`GameplayAbilitySpecHandle.h` 与
  `Tests/Network/ShooterRemoteBatchForTest.h`：这些依赖来自 Actor 自身
  （两个测试子类、成员句柄、RemoteBatch 成员），本轮**没有**净减少 include；
  收益在于纯类型不再需要 Actor 定义，新头只需 CoreMinimal 与两个前置声明。
