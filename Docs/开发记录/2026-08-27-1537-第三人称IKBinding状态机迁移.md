# 第三人称 IK Binding 状态机迁移

- 日期：2026-08-27
- 计划提交说明：`动画：第三人称IK Binding状态机迁移`
- 变更类型：生产代码 / 测试

## 目的

按《第三人称IKBinding状态机实施计划》将第三人称表现层的 Aim IK / Left Hand IK 开关判定从散落的缓存 bool 组合迁移到统一五状态模型（Unbound / WaitingForAttach / Pending / Unsupported / Ready），消除“Identity 同时表示默认值、未计算、缺失 Socket 和无效数据”的旧哨兵语义，并让 Ready / Unsupported 在依赖签名不变时零 Socket 查询、零 Transform 重算。

## 本提交完成内容

- `UShooterThirdPersonAnimInstance` 新增 `EIKBindingState` / `EIKBindingFailureReason`、公共 / Aim / LeftHand 依赖签名（`TWeakObjectPtr` 弱引用 + 显式 `operator==`）与 `FAimIKBinding` / `FLeftHandIKBinding` 结构体；实现 `Gather*Signature`、`Update*Binding`、`Rebuild*Binding`、`ResetBindingTimers`、`TickBindingTimers`、`ResetBindingsAndOutputs` 与 `ForceRebuildIKBindings()`。
- `UpdateShooterAnimationData` 重写为先 Binding 后 Aim 输入；`bAimIKEnabled` / `bLeftHandIKEnabled` 只在 `State == Ready` 时开启，Aim 输入（AimDirection 无效 / AimTarget 失效）只追加在 Enabled 表达式尾部，不改变 Binding 状态。
- Pending 1.0 秒 `LogShootGame Error` 一次后继续每帧 Rebuild 不降频；WaitingForAttach 3.0 秒（Clamp 3.0～5.0）开发期 `Warning` 一次后继续等待；异常类 Unsupported 进入时 Warning 一次，`WeaponLeftHandGripNotConfigured`（Pistol）不 Warning。
- 暴露 `AimBindingState` / `AimBindingFailureReason` / `LeftHandBindingState` / `LeftHandBindingFailureReason` 调试副本；`WaitingForAttachWarningDelaySeconds` 可配置。
- 退役 `IsAimIKEnabledForState` / `IsLeftHandIKEnabledForState` / `ShouldRefreshLeftHandGripCache` 与全部旧缓存字段；`Compute*` / `GetHandWorldTransform` 保留并删除 Identity 特判（保留 IsValid 防御）。
- `AShooterWeapon` 新增 `GetMuzzleSocketName()`；`GetThirdPersonMuzzleWorldTransform()` 缺失时回退改为 Identity（与左手握把一致）。
- `FShooterLeftHandIKMath::IsUsableFrame` 改为纯数学合法性（IsValid + Scale 各分量大于 0）。
- 新增 `Tests/Animation/ShooterIKBindingTestHarness.h`（测试角色 / 测试武器 / 测试壳）与 `Tests/Animation/ShooterIKBindingAutomationTests.cpp`（16 个 `ShootGame.Aim.Binding*` 测试，覆盖实施计划第 8 节验证矩阵）；迁移 `ShooterAimPresentationAutomationTests.cpp` / `ShooterLeftHandIKAutomationTests.cpp` 中的 Identity 断言，删除围绕退役函数的测试。
- 不修改任何 `.uasset`；AnimBP 只消费既有公开数据属性（阶段 0 已审计确认）。

## 遇到的问题

- UHT 不支持 namespace 内的 UCLASS（“GENERATED_BODY detected in a block being skipped”），且 `.generated.h` 只由同名 `.h` 生成：测试壳 UCLASS 移到独立头文件并置于文件顶层。
- `TWeakObjectPtr` 不允许 const 指针赋值（`TLosesQualifiersFromTo` 约束）且删除了隐式 bool：Gather 参数改非 const，判断改用 `IsValid()` / `Get()`。
- `NewObject<USkeletalMesh>` 上 `AddSocket` 校验 BoneName 必须存在于 RefSkeleton 的 Final 索引（Modifier 只填 Raw，需 `RebuildRefSkeleton`），且 socket 的 BoneName 非空才会让 `DoesSocketExist` 返回真。
- `AShooterCharacter` 是 `UCLASS(abstract)`，直接 `NewObject` 触发 ensure：新增非 abstract 测试角色子类。
- `UAnimInstance` 的 ClassWithin 是 SkeletalMeshComponent：测试壳用角色 Mesh 作 Outer 消除非法 Outer 警告。
- Automation Worker 进程中 `GLog->AddOutputDevice` 捕获不到日志（探针实证 count 恒 0）：日志断言改为 `AddExpectedErrorPlain`（Error 恰好一次）+ Binding 报告标志时序，不再依赖日志捕获。
- `RunNetworkSession.ps1` 默认地图 `/Game/FirstPerson/Lvl_FirstPerson` 已不存在：显式传 `-MapPath /Game/Shooter/Maps/Lvl_Shooter`。

## 处理方式

- 按上述根因逐项修正测试基础设施与签名采集代码，并用探针测试确认日志捕获不可用后改为框架级断言。
- PendingRecovery 测试利用“Ready 签名不变零重查”语义：socket 数据不在依赖签名内，修改后仍 Ready；通过清空 StoredSignature 强制 Rebuild 进入 Pending，恢复后由 Pending 的每帧 Rebuild 自动回到 Ready——同时验证了计划 5.1 的核心运行时规则。
