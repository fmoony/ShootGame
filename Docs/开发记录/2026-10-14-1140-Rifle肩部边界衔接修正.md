# Rifle 肩部边界衔接隔离修正

- 日期：2026-10-14
- 计划提交说明：`实验：消除 Rifle 收枪进入 LowReady 的肩带二次挪动`
- 类型：实验动画／Editor 取证工具／文档
- 本轮不提交，等待视觉验收。

## 目的与完成内容

用户确认肩部在收枪完成、进入 LowReady 时挪一下；本轮停止进一步抬肩。
保留当前 35% LowReady，只制作新过渡，将八节肩臂局部旋转端点匹配 Idle 起点。
校准平滑分配到同一过渡，首帧、长度、采样、状态机与正反时钟保持。
新增隔离三图、控制器／GameMode 复制体和地图，保留 HeadUpright 与原 IK。
Editor 夹具仅增加本轮路由、真实边界帧取证与绑定前安全压缩等待。

## 验证结果

- Blender／FBX 往返与平滑版导入通过，26 个采样、0.833333 s 保持。
- 八骨末帧与 LowReady 起帧 Local 旋转差小于 0.0012°。
- 72 组、21,600 帧实际图测量，12 组中途反向通过。
- 受测头颈、躯干及 ArmedAim 变换差为零，稳定 LowReady 肩高保持。
- 严格左肩边界挪动约 3.369 → 0.0079 cm；单帧约 0.697 → 0.0045 cm。
- 真实角色 168 张 TP／FP 图、84 视点，覆盖四角度和七个重点阶段。
- 真实 TP 最大边界肩点变化约 3.369 → 0.017 cm，FP 约 8.973 → 0.563 cm。
- 相机朝向保持，视点最大采样差约 0.41 mm，包含时间采样差。
- 无 IK 的手部路径发生必要端点调整；真实原 IK 下相对握持关系基本保持。
- 最终编译与真实 PIE 回归成功，零错误、一条既有 GAS 配置警告。
- 1,120 个既有文件只允许两份 Editor 夹具变化，生产及历史报告哈希保持。
- 文本版式、包含路径和 Git 空白检查通过，参数边界警告人工核对。

## 遇到的问题与处理

- 旧增量步长指标遗漏了原素材已有的绝对边界位移，新增三维胸腔相对轨迹检查。
- 初始尾段校准将移动集中在结束前，最终改为整个过渡平滑校准，保留过程证据。
- SetSkeleton 的压缩取消等待阻塞，非侵入 cdb 栈定位后取得用户明确进程结束授权。
- 只结束本轮 PID 22408，绑定前 WaitOnExistingCompression(true) 后正常生成并更新新资产。
- cdb 首次命令的符号路径吞掉命令分隔符，改用 -y 和非侵入栈命令，只读取本地符号。
- FP 仍有约 0.56 cm 肩点变化，不把 TP 改善当作完全 FP 验收，不修改净空算法。
