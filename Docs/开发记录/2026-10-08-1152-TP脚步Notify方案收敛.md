## 遇到的问题与处理方式

### 同一任务前两轮实验

- 沙箱启动曾报 `setup refresh had errors`，范围明确的操作改用沙箱外执行。
- 音频 Python Commandlet 缺少 BINKA 解码器；改用完整编辑器初始化执行脚本。
- 原素材是立体声，用 FFmpeg 转为单声道 PCM WAV，保留源文件与授权。
- 无窗口录音进程曾无法正常关闭并占用 DLL；经用户明确清理指令回收该进程。
  曾按用户要求只删除项目 Binaries，再通过注册入口生成 VS 文件、重新编译。
- `.sln` 时间戳在内容相同时不变，改用本次生成日志与 vcxproj 确认结果。
- 默认 GBK 读取中文失败；文本处理显式使用 UTF-8，并统一 CRLF。
- 录音全零时使用测试进程专用后台音量覆盖，不修改项目默认后台静音。
- 姿态采样补齐 `AnimPoseEvaluationOptions`；采样未用于重算 Notify 时间。
- Python 不能读写受保护的事件数组；使用编辑器专用入口只配置所属事件。
- 初次 Listen 的失败日志计数不足，补全诊断并调整探针换向周期后原条件重测。
- 原生夹具注册时 FP Mesh 缺失，改为实际 Character 蓝图，最终不再产生该告警。
- NPC 枪声污染及 NullRHI 空混音：正式试听用 `Lvl_Test` 加 `-RenderOffscreen`。
- 长日志参数列表曾不符合版式，复用统计字符串缩短列表后重新通过检查。
