## 目的

修复实验基础姿态与分层问题，为后续生产接入提供可核对的身体和持枪基准。
本轮以阶段 A、B 为范围，未实施生产 WeaponAction 或网络改造。

- 新增 Refined 实验目录：25 段序列、三个 BS／AO、两个原生 AnimBP。

- 统一半蹲 Idle、方向支持时序和站蹲接地采样。
- 保留腰背的渐进分层，加入 Stance 相关的持枪基准与单次 AO。
- Crouch AO 以真实 Stand 运行姿态制作，明确参考 Crouch ADS 第 0 帧。
- 仅扩展原夹具的输入、Actor 移动、原生建图与只读采集。
- 新增离线制作、指定导入、资源回归与实际运行检查工具。
- 更新当前实验说明、来源根说明与同一份工作区进度文档。
- 生产 Skeleton、正式 AnimBP、GA、角色与武器生产代码均未修改。

## 验证结果

- 使用 UsePrecompiled、NoEngineChanges 完成项目 Editor 编译。
- 25 段 RAW／COMPRESSED、循环、参考、原生图验证通过。
- 619 项数据与生产代码保护一致，来源根 README 作为当前说明单列变更。
- 原镜像资源几何验证通过，306 项旧数据不变。
- 32 方向共 5,680 帧，58 个过渡／俯仰场景共 3,480 帧。
- 鞋部最低约 -0.122／-0.238 cm；双脚表面相交为零。
- FP 位置复制差为零，完整图与 LowerOnly 的下肢对照通过。
- 稳定主方向支撑内段滑动平均约 0.02～0.06 cm/s。
- ADS 站蹲头手关系最大差约 0.525 cm，双手关系最大差约 1.43 cm。
- 已查看站蹲、移动、FP 与 LowReady 代表画面；整体视觉未通过。
- 当前实验地图与可操作 PIE 已打开供用户验收。
- 版式、空白和 include 路径检查通过；实际暂存区不改变。
- 版式工具的九条参数解析警告已人工检查；编译后仅调整四处空白换行。
- Python 脚本语法编译通过。
- 全部结果与原始数据索引见本轮验证报告。

## 遇到的问题

- CodeGraph 命令不可用，最初 MCP 服务也未运行。
- FBX 显示骨尾并非真实关节，直接使用原骨架 IK 的候选存在大幅目标误差。
- 单独校平主方向不足以修复邻向和起停。
- 静态 AO 还原不能直接代表当前运行图，早期手部候选未通过。
- 旧镜像脚本拒绝已授权修改的夹具 .cpp／.h，不能把它写成整体回归通过。
- 初次可见预览进入默认测试地图，地图参数与恢复会话的影响在视觉检查中被发现。
- FP 肩部裁切及 LowReady 左手脱离仍未解决。

## 处理方式

- 读取限定范围源码，使用只读 Python 重载图与资源，再使用官方 MCP 做可见检查。
- 使用真实关节长度的 Blender 原生控制链，所有修改烘焙到新资产。
- 统一支持时序，并以九段接地姿态承接站蹲变化，不抬高 Root。
- 从实际 Stand 图的五个俯仰输出重制 Crouch AO，重新采集验证。
- 保留旧脚本与历史报告，新增范围明确的旧资源回归。
- 修正预览参数顺序，通过 MCP 加载并确认实际实验地图。
- 数值与视觉分别报告，不以 CopyPose 或导入通过代替整体表现通过。
