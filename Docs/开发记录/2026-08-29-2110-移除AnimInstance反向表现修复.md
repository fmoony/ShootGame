## 目的

执行任务阶段 3：AnimInstance 每帧发现 `CachedPresentationWeapon != Equipment.CurrentWeaponActor` 时不再调用 `Character::EnsureWeaponPresentation`，避免动画层反向修复 Character 表现。表现收敛只由 Character / Equipment 生命周期入口负责。

## 本提交完成内容

- 审计现有生命周期入口，确认链已完整：
  - `CurrentWeaponActor` 的 `OnRep_CurrentWeaponActor` → `Character::EnsureWeaponPresentation`；
  - 服务器 `EquipWeapon` / `ClearEquippedWeapon` → 同一个幂等入口；
  - `Weapon` 的 Owner / BoundInstanceId 晚到 → `Equipment::HandleWeaponActorReady` → 同一个入口；
  - 新 AnimInstance 初始化 → `ReplayWeaponPresentationState`；
  - Unequip / 武器销毁 → Equipment 先发布 `OnWeaponPresentationChanged`，AnimInstance 清空静态 Binding。
- `ShooterThirdPersonAnimInstance.cpp`：删除 `UpdateShooterAnimationData` 中每帧 `Character->EnsureWeaponPresentation(LogicalWeapon)` 反向修复；只保留 WeakPtr stale 清理、单次 Pending 重试与帧级 Aim 输入写入。
- `ShooterThirdPersonAnimInstance.h`：更新类注释，明确“不再主动要求 Character 修复表现”。
- `ShooterIKBindingAutomationTests.cpp`：新增 `ShootGame.Aim.Binding.NoReversePresentationRepair`，在“逻辑当前值已变但表现事件未到”的窗口验证 Tick 不隐藏/Deactivate 旧 Weapon、不修改缓存与 Binding。
