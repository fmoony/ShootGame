# 修复 IK 测试打包编译错误

- 日期：2026-09-13
- 计划提交说明：`测试：限制 IK Binding 自动化测试为编辑器构建`
- 变更类型：测试 / 构建修复

## 目的

修复 Windows Development 打包编译 `ShooterIKBindingAutomationTests.cpp` 时，
因调用 `USkeletalMesh::AddSocket` 产生的 C2039 错误。

## 本提交完成内容

- 将 IK Binding 自动化测试的文件级编译条件从 `WITH_DEV_AUTOMATION_TESTS`
  收紧为 `WITH_DEV_AUTOMATION_TESTS && WITH_EDITOR`；
- 同步更新文件末尾的条件编译说明；
- 删除 First Person 捕获工具中不需要跨 Tick 保存的 `GrantedWeapon` 状态，
  改为授予代码块内的局部指针。

## 遇到的问题

- 测试注册使用 `EditorContext`，但原文件级编译条件未限制 `WITH_EDITOR`；
- UE 5.6 中 `USkeletalMesh::AddSocket` 的声明与实现均受 `WITH_EDITOR` 保护，
  Development 打包仍可能启用 `WITH_DEV_AUTOMATION_TESTS`，从而编译到不可用成员。
- 原错误消除后，MSVC 14.38 对 Lambda 局部类中不必要的 `TObjectPtr` 状态稳定触发 C1001。

## 处理方式

- 让编译边界与测试的 EditorContext 运行边界一致，不修改生产代码，
  也不直接操作 SkeletalMesh 的内部 Socket 容器来模拟 Editor-only API；
- 将只在当前授予分支中使用的武器指针缩小到局部作用域，避免改变工具的跨 Tick 状态与生命周期。
