## 目的

收尾用户在编辑器内完成的音频与动画资产整理：为 AWP / 榴弹发射器开火音效接入距离衰减，把换弹音效配置扩展到 AWP / 榴弹发射器，接线 Pistol 第三人称换弹恢复事件，并清理第一人称 Pistol 的调试打印节点，使工作区收敛到已验证状态。

## 本提交完成内容

- 开火音效衰减：新增 `SA_Fire_AWP`、`SA_Fire_GrenadeLauncher`（SoundAttenuation）并分别挂到 `SW_Fire_AWP`、`SW_Fire_GrenadeLauncher` 的 AttenuationSettings；新增公共衰减资产 `SA_Fire_Normal`、`SA_Weapon_Foley`（暂无消费者，供后续音效统一使用）。
- 模板音效归位：`FirstPersonTemplateWeaponFire02/03` 由 `Content/Weapons/GrenadeLauncher/Audio/` 移至 `Content/Weapons/_PublicAudio/`。
- 换弹音效配置扩展（承接上一提交的换弹音效功能）：`BP_ShooterWeapon_AWP` 配置 `ReloadMagazineOutSound / ReloadMagazineInSound / ReloadCockingSound` 三个音效（弹匣出 / 弹匣入 / SW_Cock）；`BP_ShooterWeapon_GrenadeLauncher` 添加换弹音效属性（Cocking=SW_Cock）并调整 `RefireRate` 与 `ReloadDuration` 数值。
- 动画蓝图调整：`ABP_TP_Pistol` 接入 `AnimNotify_ReloadRecovery` 事件调用 `BeginReloadPresentationRecovery()`（与 Rifle 同构的换弹表现恢复接线）；`ABP_FP_Pistol` 移除 Print String / Print to Log 等调试节点；`ABP_TP_Rifle` 图结构微调。
- 新建本开发记录。
