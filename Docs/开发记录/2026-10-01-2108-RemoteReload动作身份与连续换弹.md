## 遇到的问题

- 初始测试准备 RPC 的跨 Actor 参数未解析，夹具 Step 0 超时。
  同期正式 Equipment 当前武器已有效，不能归因于生产装备复制失败。
- 夹具额外等待 Remote 保留旧 true / Recovery，主动刷新已送达 false，导致超时。
- 延迟场景成功后，关闭客户端触发夹具的发起者丢失误报。
- Magazine 测试清理临时 World 时出现 World has no context 警告，没有断言失败。

## 处理方式

- 夹具用稳定 PlayerId 找到实际复制角色，从 Equipment 固定武器目标。
  持续校验角色、武器、ASC、Avatar 与真实状态机，不把 Invalid 当作通过。
- 不等待观察端保留旧 true，也不强制等待 false；连续 true 独立验证。
- 成功时对全部服务器参与者置 Finished，再重跑正常与延迟会话。
- 既有 Magazine 清理警告如实保留，不扩展本次修复范围。

## 遗留项

- 单个复制 ID 表达最新动作，不保证任意丢包或极短取消下回放全部历史动作。
- 原始某一次第二轮无反应现场尚未唯一归因；诊断可区分拒绝与接受后的漏识别。
- Remote 开始仍有相位延迟：正常 7～23ms，PktLag=100 下 108～144ms。
  本轮不实现 ServerStartTime / Duration，也不处理 Magazine Notify 跳帧恢复。
- Ammo Prediction、HUD、Fire 架构与丢包验证矩阵均留待后续独立阶段。
