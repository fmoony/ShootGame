- 日期：2026-08-29
- 计划提交说明：`装备：收束当前武器逻辑变化事件`
- 变更类型：生产代码 / 测试

## 目的

执行《武器装备表现事件收束与动画切换解耦执行计划》E2：把 `OnEquippedWeaponChanged` 从“Apply 附带广播”改为 Previous / Current 语义，只在 `CurrentWeaponActor` 真实转移时发布；`ActiveWeaponInstanceId` OnRep 不再触发表现应用；BeginPlay / HandleWeaponActorReady 只做表现补做，不再产生逻辑事件。

## 本提交完成内容

- `Source/ShootGame/Characters/Equipment/ShooterEquipmentComponent.h/.cpp`：
  - `FShooterEquippedWeaponChangedDelegate` 签名改为 `(AShooterWeapon* PreviousWeapon, AShooterWeapon* CurrentWeapon)`（E0 已确认无 C++ / 蓝图生产订阅者）。
  - `EquipWeapon`：提交原子对后仅当 Previous != Target 时广播；相同武器重复提交不发布第二次逻辑变化。
  - `ClearEquippedWeapon`：Unequip 广播一次 `(Previous, nullptr)`；重复 Clear 不重复发布。
  - `OnRep_CurrentWeaponActor`：广播逻辑事件 → 表现应用；Unequip 时显式清空 Aim 平滑。
  - `OnRep_ActiveWeaponInstanceId`：只记录日志，不再调用 Apply。
  - `ApplyCurrentWeapon`：收敛为纯表现应用（附着 + Activate），移除事件广播；E3 将由 Character::EnsureWeaponPresentation 取代。
- 新增 `Source/ShootGame/Tests/Equipment/ShooterEquipmentLogicalEventAutomationTests.cpp`：
  - `LogicalChangeSemantics`：首次装备 / 重复装备 / 切枪 / Unequip / 重复 Clear 的事件次数与 Previous/Current 参数。
  - `ActiveInstanceIdNoApply`：ActiveId OnRep 不应用表现、不广播事件。
  - `CurrentWeaponSemantics`：OnRep 的 null→weapon / 同值 / weapon→null 语义与表现后置条件。
