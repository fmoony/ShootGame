# Blender 下蹲接地与骨骼运行验证

- 日期：2026-11-14
- 计划提交说明：修复：将隔离下蹲接地转入 Blender 并增加运行骨骼验证。
- 变更类型：测试 / 工具 / 资产 / 文档
- 状态：稳定动作工作区完成；启停过渡保留问题，未提交或推送。

## 目的

取消实验 C++ 对腿部接地的直接补偿，改由 Blender 制作动画。
以实际运行的骨骼数据判定接触和脚滑，截图仅作辅助检查。
本轮使用用户明确指定的 UE 5.8 工作树与原 Stance 地图。

## 本提交完成内容

- 关闭误启动的 UE 5.6 查询进程，按授权管理 UE 5.8 会话。
- 移除方向混合腿部 IK、运行时骨盆穿地补偿和旧 C++ 接地烘焙。
- 保留手部 Grip、脊柱瞄准和普通动画混合。
- 使用 Blender 4.5.8 LTS bpy 实际求值并烘焙支撑、摆腿和膝盖轨道。
- 制作 44 向及两套持枪姿态，合计 90 段动作。
- 移动为 60 FPS / 1 秒，完整 idle 保持 30 FPS / 约 6.7 秒。
- C++ 导入器只复制 Blender 已烘焙轨道，不计算接地。
- 保留 blend、FBX、bpy 求值轨道与固定的原实验输入快照。
- 增加实际 Body 采样、逐场景分析、资源重载与 blend Action 回读。
- 更新当前说明和工具入口，未接入正式 AnimBP 或网络角色。

## 验证结果

- 最终项目 Editor 构建通过，使用 UsePrecompiled 与 NoEngineChanges。
- 90 段资源重载、骨长、循环、RAW / COMPRESSED 与上身保护通过。
- Blender 到 UE 的最大组件位置往返误差约 0.00136 cm。
- 原动作上身局部位置差约 0.000048 cm，旋转差约 0.000623°。
- blend 的 90 个 Action 回读位置差为 0，旋转差约 0.0000042°。
- 实际运行 264 场景、43,808 帧，每帧保存 14 个骨骼或参考点。
- 稳定段双脚同时高于 1 cm 的帧为 0，最低参考接触约 -0.322 cm。
- 最差场景支撑高度 P99 约 0.416 cm，脚滑 P95 约 3.694 cm/s。
- 腿部骨长最大误差低于 0.000002 cm，未放宽逐场景门禁。
- 启停、转向和切换全程另行记录，不以稳定段替代过渡验收。
- D3D12 移动与握持、文本和 Include 检查见本轮证据目录。
- 原始 FBX、正式 Skeleton、AnimBP、地图和 FP 网格共 21 项哈希不变。
- 未新建、移动或删除 C++ 文件，不触发 VS 工程刷新。
- 未运行全量自动化、网络、正式下蹲、Cook 或完整滑铲回归。

## 遇到的问题

- 受限进程查询漏掉 UE 5.8，初期误读取 UE 5.6 目录。
- 无窗口 UE 5.6 未响应普通关闭，用户明确授权后结束。
- 自动审批未认可旧确认覆盖 UE 5.8，再次明确确认后正常关闭。
- 原路径没有 Blender，官方包下载超时，清华镜像返回 403。
- 既有 Blender 骨架的 root 由 Armature 对象承载，姿态骨只有 88 根。
- 第一版单段接地通过，但实际方向混合仍明显穿地和悬空。
- 第二版消除悬空，少数方向仍穿地约 1.47 cm。
- 初次骨长检查误将可平移的 ik_hand 标记视为变形骨。
- 横移二次重采样造成约 1.86 mm / 0.45° 上身偏差。
- Blender 不允许直接覆盖正在作为 Action 库读取的 blend。
- 当前启停混合仍有最低约 -2.92 cm 的短暂参考点穿地。

## 处理方式

重新以 UE 5.8 为基线，精确备份并保护原始资产。
bpy 安装于项目 Saved/Tools，使用阿里云镜像取得固定版本。
没有修改系统 Python、引擎 Python 包或 UE 引擎源码。

先采集 40 场景、7,511 帧旧数据，再移除 C++ 补偿。
Blender 统一支撑节奏、固定支撑期脚姿态并匹配实验移速。
根据失败数据局部补样本，移动轨道提高到 60 FPS。
候选和失败报告保留在 Saved，没有降低接地阈值。

骨长门禁约束变形骨，IK 标记另作往返一致性检查。
四段横移改为直接重采样，保留原上身轨道。
局部 blend 先写独立更新文件，再在 bpy 退出后替换源文件。
对完整 blend 求值回读，证明实际 Action 与导入轨道一致。

[Blender Bake Action 官方说明][bake]用于核对逐帧烘焙和 Action。
[Blender IK 官方说明][ik]用于核对离线关节求解职责。
本地 UE 5.8 AnimationDataController 用于逐轨道写入与保存。
运行数据读取实际 Body，不通过截图宣布接地通过。

## 遗留项
