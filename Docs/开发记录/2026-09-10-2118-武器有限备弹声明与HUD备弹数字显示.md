# 武器有限备弹声明与HUD备弹数字显示

- 日期：2026-09-10
- 计划提交说明：`武器：声明有限备弹并在HUD显示备弹数字`
- 变更类型：生产代码 / 测试

## 目的

把「有限备弹」从 Inventory 侧的隐式启发式（MagazineSize×3）正式声明到武器上，并让 ReserveAmmo 流通到本地 HUD，在子弹条 UI 上以数字形式显示备弹，解决玩家无法感知剩余换弹次数的问题。

## 本提交完成内容

- `Weapons/ShooterWeapon.h/.cpp`：Ammo 分类新增 `InitialReserveAmmo`（默认 -1 自动=MagazineSize×3，>=0 显式有限值）与封闭弹药经济注释；新增 `GetInitialReserveAmmo()`、`GetReserveAmmo()`（绑定 Inventory 时读权威 ReserveAmmo，未绑定旧路径返回 0）。
- `Inventory/ShooterInventoryComponent.h/.cpp`：`ShooterInventory::GetInitialReserveAmmoForWeaponClass` 声明提升到头文件，实现改为优先采用武器显式声明，-1 保持兼容基线；`TryAddWeapon` 入库路径不变。
- HUD 链路扩 ReserveAmmo 参数（纯表现层，不新增网络闭环，备弹已随 FastArray COND_OwnerOnly 复制）：
  - `Weapons/ShooterWeaponHolder.h` 接口、`Characters/ShooterCharacter` 委托 `FBulletCountUpdatedDelegate` 与实现、`AI/ShooterNPC` 空实现、`GameFramework/ShooterPlayerController` 转发。
  - 武器侧三个 HUD 调用点（`RefreshAmmoMirror`、`OnRep_CurrentBullets`、NPC 旧路径）均传备弹。
  - 顺带修复 `ShooterCharacter.cpp` `OnWeaponActivated` 中 `UpdateWeaponHUD(GetMagazineSize(), GetBulletCount())` 参数对调的既有缺陷（弹匣未满时 HUD 两值互换）。
- `UI/ShooterBulletCounterUI.h/.cpp`：新增 C++ 入口 `UpdateBulletCounter(MagazineSize, BulletCount, ReserveAmmo)`，先写原生 TextBlock 再转发 `BP_UpdateBulletCounter`；`NativePreConstruct` 用 `WidgetTree->ConstructWidget` 创建 `ReserveAmmoText` 挂到根面板（Canvas 右上锚点 / Overlay 右下对齐），仅显示数字、无状态色。**与批准计划的偏差**：原计划经 McpAutomationBridge 改蓝图资产，但该桥不支持设计器树新增控件，也不支持新建 WidgetBP，改用 C++ 原生 TextBlock，蓝图资产零改动（事件节点引脚随父类签名自动刷新）。
- 测试：新增 `Tests/Inventory/ShooterInventoryReserveTestTypes.h` + `ShooterInventoryReserveDeclarationAutomationTests.cpp`（显式声明/零备弹/默认 -1 三态 + 未绑定读取为 0）；新增 `Tests/UI/ShooterBulletCounterReserveAutomationTests.cpp`（加载真实 `UI_ShooterBulletCounter` 资产，断言文本控件创建、挂接与数字写入）；`ShooterWeaponPresentationTestTypes.h` 监听器签名同步扩参。

## 遇到的问题

- `ShooterCharacter.cpp` `OnWeaponActivated` 的 HUD 调用参数顺序与接口相反（既有缺陷，弹匣未满时 HUD 数值对调）。
- McpAutomationBridge 无法在 Widget 设计器树新增控件（`UI_ShooterBulletCounter` 树内只有 Image/ProgressBar，无文本控件），无法按原计划改蓝图。
- 工作区存在本轮之外的未提交改动：`ShooterPickup.cpp`、`ShooterEquipmentLogicalEventAutomationTests.cpp`、`Docs/开发记录/2026-09-10-1927-*`，以及编辑器会话中完成的 Content 资产移动（`Content/Shooter/UI/*` → `Content/Shooter/Blueprints/UI/`，`BP_ShooterPlayerController.uasset` 修改）。

## 处理方式

- 参数对调随本次改调用点一并修正，并加注释提示接口参数顺序与 Getter 阅读顺序相反。
- UI 方案改为 C++ 原生 TextBlock（见"完成内容"偏差说明）；自动化测试直接加载移动后的真实资产路径 `/Game/Shooter/Blueprints/UI/UI_ShooterBulletCounter` 并通过。
- 提交时显式只暂存本轮文件，排除用户未提交的 Content 移动与上述无关改动。

- 备弹低量/耗尽状态色提示（按用户要求本轮明确不做）。
- WeaponDefinition 数据资产正式化（Inventory 注释中的长期方向，届时 `GetInitialReserveAmmoForWeaponClass` 桥接可移除）。
- 备弹数字的视觉细节（字号/位置）未做 PIE 人工目检，可按需微调 `ShooterBulletCounterUI.cpp` 中的锚点与尺寸。
