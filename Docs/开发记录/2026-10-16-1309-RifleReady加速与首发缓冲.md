# RifleReady 双向加速与一次首发缓冲

- 日期：2026-10-16
- 计划提交说明：`feat：加快 RifleReady 双向过渡并在真实端点消费首发`
- 变更类型：生产代码 / 测试 / 文档

## 目的与授权

在上一轮 Walk / Sprint 未提交实现上，完成用户要求的第一版快速收抬枪。
用户明确将原即时射击改为一次首发缓冲，提前松开不取消，动作中断或超时作废。
编辑器保存与本轮不自行修改已重新确认；原 ShootGame 编辑器已正常关闭。
本轮未提交、未推送；未改历史开发记录、动画资源、分层图或 IK。

## 本轮完成内容

- ShooterThirdPersonAnimInstance 新增 RifleLowerDuration / RifleRaiseDuration，均默认 0.32 秒。
- 现有约 0.833333 秒素材以约 ±2.604 倍速播放；中途反向保留累计时间和选片锁存。
- Local Space、头颈、肩部、IK、正反状态机图与素材均保持原样。
- Character 缓存最多一次首发，绑定当前武器，0.55 秒绝对游戏时间过期，重复点击不续期。
- 仅真实播放器达到瞄准端点后，PC 输入解释才将一次 Edge 或持续 Held 交给原 ASC。
- 提前松开时，同帧交付 Edge 与标准 Release，不建立 Held；首发后不再连发。
- 持续按住时，首发后回到原 GA_Fire 全自动节拍；一次尝试即消费，不重试服务器拒绝。
- Reload / Equip 输入当帧取消，外部动作标签、武器和 Avatar 失效在消费前作废。
- 死亡、失去占有及 EndPlay 清理首发；中断或超时后尚未执行的首发需重新按 Fire。
- CMC 的 Custom_2 传首发等待位，松开 Fire 后仍维持 Walk；重放后恢复当前等待位。
- GA_Fire 本地资格读真实端点，防止既有 Held 绕过；服务器原裁决与 Commit 路径不改。
- K 独立预览保持原 ±1 速率与中断规则，不驱动正式首发或 Sprint。
- 网络射击契约增加用户已确认的 RifleReady 输入窗口例外，射速门控仍不允许缓冲。

## 依据与项目差异

Epic Sequence Player API 允许负速率；本机 UE5.6 UpdateAssetPlayer 更新 PlayRate 时保留累计时间。
当前素材 RateScale 为 1；本轮只调整现有播放器幅值，没有重新制作动画或增加 AnimNode。
Epic Gameplay Ability 文档说明 TryActivateAbility 先检查资格再激活，LocalPredicted 由服务器裁决。
本机 AbilitySystemComponent_Abilities.cpp 的调用仍携带 Spec.InputPressed 与原 PredictionKey。
本项目使用已有 Edge / Held / Release 输入机制，不把 GA_Fire 延长为跨动画窗口的 Ability。
Dedicated 不使用渲染动画或另一个倒计时作为权威事务时钟；等待只发生在本地输入层。

- [Epic Sequence Player 速率](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/Animation/FAnimNode_SequencePlayer_Standal-/GetPlayRate)
- [Epic UE5.6 Gameplay Ability](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-gameplay-abilities-in-unreal-engine?application_version=5.6)

### Invariant 2 Local Prediction Obeys Weapon Rules

- 触及：快速双向播放、首发固定窗口、松开保留、动作中断取消。
- 不变：原武器身份、射速、全自动 Held、预测预算与结清规则。
- 新证据：单击只消费一次、重复点击不续期、超时与中断无迟发。
- 范围：不使用远端 Ammo 或复制姿态否决本地有效 Shot Intent。

### Invariant 3 Server Is Final Authority

- 触及：到位后的输入仍只通过原 GAS TryActivateAbility 提交。
- 不变：服务器校验身份、弹药、射速和动作标签；拒绝不产生结果。
- 新证据：实际 Dedicated 中一发对应一次 Commit 与弹药消耗。
- 范围：Dedicated 不运行用于 Gameplay 计时的渲染动画或新增射击时钟。

### Invariant 4 Remote Is Confirmed Only

- 触及：远端收抬枪加速，Sprint 仍来自 CMC 权威状态。
- 不变：远端开火表现仍只来自服务器 Commit。
- 新证据：双客户端远端姿态和原射击确认链回归。
- 范围：不提高纯表现不可靠 RPC 的送达保证。

### Invariant 5 Exactly One Authority Result

- 触及：仅一份待执行首发意图，固定有效期且不能重复消费。
- 不变：一 Activation 一 Commit，Projectile 与伤害路径不改。
- 新证据：松开首发次数、持续连发、取消后零新增结果。
