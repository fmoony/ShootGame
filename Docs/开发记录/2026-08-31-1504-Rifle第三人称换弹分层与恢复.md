## 遇到的问题

- 最初同时硬关闭 Aim IK 与左手 IK，换弹会回到水平姿势并在结束时跳变。
- 直接把 Rifle AimOffset 叠到 Reload 后会与资源自带的双臂动作冲突，俯仰越大错位越明显。
- 初版分级 Mask 方案认为 `ArmedAimPose` 足以传递俯仰，因此旁路了 Reload 分支的脊柱修正；实际双臂权重为 `1.0` 时，Reload 姿势完全覆盖手臂俯仰，导致换弹仍保持水平。
- Reload 动画末段与 Gameplay Reload 时长不完全一致时，可能出现表现未收尾但已经允许开火，或 Recover Notify 迟到后重入 Reload 的问题。
- 首轮自动化把 `ReloadDuration` 错误约束为必须与 Sequence Length 完全相等；实测资产值为 `2.5s` 与 `2.2s`，该差值是为表现收尾保留的权威余量，不是配置错误。

## 处理方式

- 使用 `ReloadIKAlpha` 驱动两套 IK 的连续表现权重，不再用 Reload Bool 硬切 Alpha。
- 使用 `ReloadRecovery` 作为纯表现收尾信号，并用权威 `bIsReloading` 防守迟到事件。
- 通过分级 Blend Mask 保留头颈实时瞄准，只让 Reload 资源完整控制锁骨、双臂和手指。
- 在 Reload 源姿势进入遮罩合成前恢复 `spine_01/02/03` 分布式 `AimPitchDegrees` 修正，使完整双臂动作随瞄准俯仰运动。
- 保持 Rifle `ReloadDuration=2.5s` 覆盖 `2.2s` Sequence 与表现收尾，并将自动化约束修正为“权威时长不得短于动画”。
