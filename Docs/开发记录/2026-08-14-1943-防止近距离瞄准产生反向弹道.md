# 防止近距离瞄准产生反向弹道

## 日期

2026-08-14 19:43（Asia/Shanghai）

## 计划提交说明

`修复：防止近距离瞄准产生反向弹道`

## 变更类型

- 射击逻辑修复
- 网络自动化稳定性

## 目的

摄像机射线在近距离命中枪口后方物体时，目标点可能落在枪口后方。原实现始终让弹丸朝该目标点生成，导致服务器生成方向与玩家控制方向相反，既会破坏实际射击表现，也会让网络自动化校验偶发失败。

本提交只修复弹丸生成方向，不包含默认地图与默认 GameMode 切换。

## 本提交完成内容

- 在 `AShooterWeapon::CalculateProjectileSpawnTransform` 中取得角色控制旋转的前向向量。
- 当“枪口到目标点”的方向落在控制方向的非前向半球时，使用控制方向计算枪口前方的生成位置，避免弹丸在枪口后方生成。
- 应用散布后再次检查最终弹道方向；若仍落在控制方向的非前向半球，则回退到控制方向，避免弹丸反向发射。
- 正常位于前方的准星目标和原有散布逻辑保持不变。

## 遇到的问题

- 在验证 Shooter 默认入口切换时，DedicatedNetwork 出现 `Projectile aim differs from server control rotation`，曾记录到 `dot=-0.289` 和 `dot=-0.906`。
- 自动化协调器已临时将 `AimVariance` 设为 0，因此本次失败并非随机散布造成，而是摄像机射线目标偶尔位于枪口后方。

## 处理方式

- 先回退尚未提交的默认入口配置，使问题修复和配置切换保持为两个独立、可审查的提交。
- 在生产射击逻辑中增加半球检查，而不是放宽自动化阈值或掩盖失败；这样同时修复实际玩法中的反向弹道风险。
