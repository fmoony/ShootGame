# 固定 Rifle 左手握持校准基线

- 日期：2026-08-25
- 计划提交说明：`动画：固定 Rifle 左手握持校准基线`
- 变更类型：生产代码 / 测试 / 资产 / 文档 / 构建

## 目的

完成 Rifle 第三人称左手握持闭环，使左手掌参考帧能够在最终 `Shooter Aim IK` 之后稳定对齐武器握把，并把已经通过人工视觉验收的结果保存为后续贴墙、同步和双臂姿势优化的可回退基线。

## 本提交完成内容

- 新增 Runtime `FAnimNode_ShooterLeftHandIK`、纯数学求解器和 Editor AnimGraph 节点外壳。
- 左手 IK 使用 `upperarm_l → lowerarm_l → hand_l` 两骨骼链求解位置，并用完整握把参考帧恢复手腕旋转。
- `UShooterThirdPersonAnimInstance` 增加角色 `HandGrip_L` 相对 `hand_l` 的参考帧、双参考帧有效性判定和缓存刷新条件。
- 为 `ShootGame` 增加运行时 `AnimationCore` 依赖。
- 补充左手握把相对变换、双参考帧闭合、启用状态矩阵和缓存刷新 Automation Tests。
- 在角色与 Rifle 资产中保存手掌参考 Socket、武器握把配置和最终校准结果；`ABP_TP_Rifle` 保持 `Shooter Aim IK → Shooter Left Hand IK` 顺序。
- 保留当前 Rifle 左手校准 Transform 作为视觉基线：Location `(-29.886, 7.307, -1.157)`，Rotation XYZ `(95.203, 9.546, -120.477)`。
- 新建《武器贴墙稳定与瞄准表现收尾实施计划》，将未执行的同步调参、贴墙稳定和双臂姿势问题统一纳入新的分阶段计划。
- 更新旧计划状态和 `AGENTS.md` 导航，避免外部 Agent 继续执行已被替代的 N1/N2 参数调优路线。

## 遇到的问题

- 仅将武器握把位置作为 Two Bone IK 末端会让手腕到达目标，但手掌和拇指方向无法完整贴合。
- 第一人称 `Ctrl_Hand_L` Offset 在 Details 面板中以 XYZ 显示，和 `FRotator` 的 Pitch/Yaw/Roll 语义顺序不同，初次测试发生轴分量错位。
- 临时测试中 `Compose Transforms` 的输入顺序曾接反，导致左臂姿势完全错误。
- Skeletal Mesh 资产在编辑器仍占用或加载状态下曾出现保存失败，需要关闭相关资产/编辑器后重试。

## 处理方式

- 引入角色 `HandGrip_L` 与武器握把两个完整参考帧，使求解结果同时满足位置和旋转对齐，而不是只把 `hand_l` 骨骼原点移动到武器 Socket。
- 明确 Transform 面板 XYZ 与 Rotator 语义映射，并使用经过视觉确认的校准 Transform。
- 按 `HandGripInLeftHandSpace × DesiredLeftHandInRightHandSpace` 重建 IK 所需武器握把输入，恢复正确 Compose 顺序。
- 通过 Editor Build、4 项纯计算/状态测试和人工视觉矩阵共同确认结果。

## 遗留项

- `ABP_TP_Rifle` 中用于校准的临时变量仍需要在最终清理阶段改为有意义的正式命名。
- 第一人称贴近障碍物时仍会抖动，下一步先执行固定远端 `Aim Target` 隔离实验。
- 第三人称快速转向同步仍受服务器 10 Hz 采样、变化门槛和观察端平滑叠加延迟影响。
- 快速视角移动时右手残差集中在手腕、左肘 Pole Target 不稳定等姿势问题尚未处理。
- Pistol 未接入左手 IK，必须保持关闭并在最终回归中验证。
