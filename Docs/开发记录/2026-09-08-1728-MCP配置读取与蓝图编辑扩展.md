## 遇到的问题

- 工具注册存在白名单，新配置读取工具需要同时加入 registry 白名单与 dispatch，不能只添加 schema。
- 当前编辑器进程不会自动使用新工具目录；外部构建在编辑器运行时生成热重载 DLL，需要退出后构建常规版本并重新打开工程。
- 编辑器退出时热重载 DLL 一度仍不可删除；查看退出日志、进程和 Windows Restart Manager 后，仅清理本轮 UBT 指出的单个 `UnrealEditor-ShootGame-0001.dll`，随后 UBT 正常完成其自身临时文件清理与构建。
- UE 5.6 的 GEngineIni 可能是 `Engine` 缓存键，初版误把它作为 sourceFile；已改为返回 cacheKey 与 FConfigBranch::IniPath。
- 全量 Automation 的 Rifle FP 动画映射断言失败。本轮自动化禁用 MCP 插件；未为通过该检查修改游戏代码或用户动画资产。
- 写文档时一次 apply_patch 同时删除/新增同一文件被工具拒绝，没有产生文件改动；随后用单次文件写入完成。
