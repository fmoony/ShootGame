# Metal / Dirt 脚步素材来源

- 素材包：[Footsteps on different surfaces](https://opengameart.org/content/footsteps-on-different-surfaces)。
- 整理作者：congusbongus；发布包授权 CC BY 3.0，需要保留署名。
- Metal：Eelke 的 boots on aluminum ladder 01；真实靴子踩铝梯的单步片段。
- Dirt：swuing 的 footstep-grass.wav；草土、草叶质感，用于本阶段的 Dirt 地面。
- Dirt 素材不是纯裸土录音；后续可以在 DataAsset 中替换为更合适的干土素材。
- 原始作者链接和包内授权分别保存在 License-Metal.txt、License-Dirt.txt。
- 原始作者当前 Freesound 页面标注 CC BY 4.0。
  本次使用的是发布包中按 CC BY 3.0 提供的整理片段。
- 转换：OGG 解码为单声道 16-bit PCM WAV。
  保持采样率、音量和完整单步片段，不复制 Concrete 音源。
- Metal 为 48kHz，Dirt 为 44.1kHz；每种地面选用五个变体。
  对应关系与 SHA-256 见 Manifest.json。
- 资产目录：/Game/Shooter/Audio/Footsteps；共享配置：DA_FootstepSounds。
